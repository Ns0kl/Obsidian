# 可変・不変（Mutable & Immutable）

## 概要

Pythonのデータ型は、**ミュータブル**（変更可能）と**イミュータブル**（変更不可）に分類されます。

## データ型の分類

### イミュータブル（変更不可）

| 型 | 例 | 説明 |
|---|---|---|
| `int` | `42`, `-5` | 整数 |
| `float` | `3.14`, `1.0` | 浮動小数点数 |
| `str` | `'hello'`, `"world"` | 文字列 |
| `tuple` | `(1, 2, 3)` | タプル |
| `frozenset` | `frozenset({1, 2})` | 不変集合 |
| `bool` | `True`, `False` | 論理値 |
| `bytes` | `b'hello'` | バイト列 |
| `None` | `None` | ヌル値 |

### ミュータブル（変更可能）

| 型 | 例 | 説明 |
|---|---|---|
| `list` | `[1, 2, 3]` | リスト |
| `dict` | `{'key': 'value'}` | 辞書 |
| `set` | `{1, 2, 3}` | 集合 |
| （クラスインスタンス） | `obj` | クラスのインスタンス |

## イミュータブルな型の特性

### 文字列は不変

```python
s = 'hello'
# s[0] = 'H'  # TypeError: 'str' object does not support item assignment

# 新しい文字列を作成する
s_new = 'H' + s[1:]
print(s_new)  # 'Hello'
print(s)      # 'hello'（元のままの文字列）
```

### タプルは不変

```python
t = (1, 2, 3)
# t[0] = 10  # TypeError: 'tuple' object does not support item assignment

# 新しいタプルを作成
t_new = (10,) + t[1:]
print(t_new)  # (10, 2, 3)
print(t)      # (1, 2, 3)
```

### イミュータブルなオブジェクトはIDが変わらない

```python
s1 = 'hello'
s2 = s1
print(id(s1) == id(s2))  # True（同じオブジェクト）

s1 = s1 + ' world'
print(id(s1))  # 変わった（新しいオブジェクトが作成された）
print(id(s2))  # 変わらない
```

## ミュータブルな型の特性

### リストは可変

```python
lst = [1, 2, 3]
lst[0] = 10
print(lst)  # [10, 2, 3]

lst.append(4)
print(lst)  # [10, 2, 3, 4]
```

### ミュータブルなオブジェクトのID

```python
lst1 = [1, 2, 3]
lst2 = lst1
print(id(lst1) == id(lst2))  # True（同じオブジェクト）

lst1.append(4)
print(lst2)  # [1, 2, 3, 4]（lst2も変わった）

# 新しいリストを再代入した場合
lst1 = [1, 2, 3, 4, 5]
print(id(lst1) != id(lst2))  # True（異なるオブジェクト）
print(lst2)  # [1, 2, 3, 4]（変わらない）
```

## 参照とコピー

### 参照

```python
# ミュータブルな型
original = [1, 2, 3]
reference = original  # 参照（同じオブジェクトを指す）

reference.append(4)
print(original)   # [1, 2, 3, 4]（一緒に変わった）
print(reference)  # [1, 2, 3, 4]

# イミュータブルな型
str1 = 'hello'
str2 = str1       # イミュータブルなので安全
str1 = str1 + ' world'
print(str2)       # 'hello'（変わらない）
```

### 浅いコピー（Shallow Copy）

```python
original = [1, 2, [3, 4]]
copy_shallow = original[:]
# または
copy_shallow = original.copy()

copy_shallow[0] = 99
print(original[0])  # 1（変わらない）

copy_shallow[2][0] = 99
print(original[2][0])  # 99（ネストされたリストは共有される）
```

### 深いコピー（Deep Copy）

```python
import copy

original = [1, 2, [3, 4]]
copy_deep = copy.deepcopy(original)

copy_deep[0] = 99
copy_deep[2][0] = 99

print(original)  # [1, 2, [3, 4]]（全く変わらない）
print(copy_deep)  # [99, 2, [99, 4]]
```

## 関数への引数の渡し方

### イミュータブルな型

```python
def modify_immutable(x):
    x = x + 10  # 新しいオブジェクトが作成される
    return x

value = 5
result = modify_immutable(value)
print(value)   # 5（変わらない）
print(result)  # 15
```

### ミュータブルな型

```python
def modify_list(lst):
    lst.append(4)  # 元のリストが変更される
    return lst

my_list = [1, 2, 3]
result = modify_list(my_list)
print(my_list)  # [1, 2, 3, 4]（変わった）
print(result)   # [1, 2, 3, 4]
```

### 安全な修正（コピーを作成）

```python
def modify_list_safe(lst):
    lst_copy = lst.copy()  # コピーを作成
    lst_copy.append(4)
    return lst_copy

my_list = [1, 2, 3]
result = modify_list_safe(my_list)
print(my_list)  # [1, 2, 3]（変わらない）
print(result)   # [1, 2, 3, 4]
```

## 実装による違い

### 不変オブジェクトの最適化

```python
# 小さな整数はキャッシュされる
a = 256
b = 256
print(a is b)  # True（同じオブジェクト）

a = 257
b = 257
print(a is b)  # False（異なるオブジェクト - ただし計時依存）

# 文字列の最適化
s1 = 'hello'
s2 = 'hello'
print(s1 is s2)  # True（Pythonが最適化）
```

## ハッシュ可能性

イミュータブルなオブジェクトのみがハッシュ可能です：

```python
# ハッシュ可能（辞書のキーに使用可能）
hash((1, 2, 3))      # OK
hash('hello')        # OK
hash(42)             # OK

# ハッシュ不可（エラー）
# hash([1, 2, 3])    # TypeError
# hash({'key': 'value'})  # TypeError

# 辞書のキーの例
coordinates = {
    (0, 0): 'origin',
    (1, 1): 'diagonal'
}

# [0, 0]はハッシュ不可
# coordinates[[0, 0]] = 'origin'  # TypeError
```

## 📌 重要なポイント

- **イミュータブル**: `int`, `float`, `str`, `tuple`, `frozenset`
- **ミュータブル**: `list`, `dict`, `set`
- **参照 vs コピー**: ミュータブルなオブジェクトは注意が必要
- **浅いコピー vs 深いコピー**: ネストされたデータ構造では使い分けが重要
- **ハッシュ可能**: イミュータブルなオブジェクトのみ
- **関数への引数**: ミュータブルな型は元のオブジェクトが変更される
