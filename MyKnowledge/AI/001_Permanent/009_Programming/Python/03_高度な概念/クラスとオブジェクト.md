# クラスとオブジェクト

## 概要

**クラス**は、データ（メンバ変数）とその操作（メソッド）をまとめたテンプレートです。クラスから作成されたインスタンスがオブジェクトです。

## クラスの基本

### 最小限のクラス

```python
class Point:
    def __init__(self):
        self.x = 0.
        self.y = 0.

p = Point()
print(type(p))  # <class '__main__.Point'>
print(p.x)      # 0.0
print(p.y)      # 0.0
```

### インスタンス化と初期化

```python
class Point:
    def __init__(self, x=0, y=0):
        self.x = x
        self.y = y

p1 = Point()           # デフォルト値を使用
print(p1.x, p1.y)      # 0 0

p2 = Point(3, 4)
print(p2.x, p2.y)      # 3 4

p3 = Point(x=5, y=6)
print(p3.x, p3.y)      # 5 6
```

## メソッド

### インスタンスメソッド

```python
class Point:
    def __init__(self, x=0., y=0.):
        self.x = x
        self.y = y
    
    # setter（値をセット）
    def set(self, x, y):
        self.x = x
        self.y = y
    
    # 座標を入れ替える
    def transpose(self):
        self.x, self.y = self.y, self.x
    
    # 値の合計を返す
    def sum(self):
        return self.x + self.y
    
    # 内積を計算
    def dot(self, other):
        return self.x * other.x + self.y * other.y

p = Point(1, 2)
p.set(3, 4)
print(p.x, p.y)        # 3 4

p.transpose()
print(p.x, p.y)        # 4 3

print(p.sum())         # 7

q = Point(2, 5)
print(p.dot(q))        # 4*2 + 3*5 = 23
```

### クラスメソッドとスタティックメソッド

```python
class MyClass:
    class_var = 10
    
    # クラスメソッド
    @classmethod
    def class_method(cls):
        return f'Class variable: {cls.class_var}'
    
    # スタティックメソッド
    @staticmethod
    def static_method(x, y):
        return x + y

print(MyClass.class_method())      # Class variable: 10
print(MyClass.static_method(3, 5))  # 8
```

## 継承

### 継承の基本

```python
# 基底クラス
class Point:
    def __init__(self, x=0., y=0.):
        self.x = x
        self.y = y
    
    def sum(self):
        return self.x + self.y

# 派生クラス
class Point3D(Point):
    def __init__(self, x=0., y=0., z=0.):
        super().__init__(x, y)  # 基底クラスの__init__を呼び出す
        self.z = z

p = Point3D(3, 4, 2)
print(p.sum())         # 7（x + y）
print(p.z)             # 2
```

### メソッドのオーバーライド

```python
class Point:
    def __init__(self, x=0., y=0.):
        self.x = x
        self.y = y
    
    def sum(self):
        return self.x + self.y

class Point3D(Point):
    def __init__(self, x=0., y=0., z=0.):
        super().__init__(x, y)
        self.z = z
    
    # sum()をオーバーライド
    def sum(self):
        return self.x + self.y + self.z

p = Point(2, 3)
print(p.sum())         # 5

p3d = Point3D(2, 3, 4)
print(p3d.sum())       # 9
```

## プライベート属性とメソッド

```python
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance  # プライベート属性
    
    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
    
    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
    
    def get_balance(self):
        return self.__balance

account = BankAccount(1000)
account.deposit(500)
print(account.get_balance())     # 1500

# 直接アクセスはできない
# print(account.__balance)  # AttributeError

# ただしアクセスできる方法がある（強制されない）
print(account._BankAccount__balance)  # 1500
```

## プロパティ

```python
class Person:
    def __init__(self, name, age):
        self._name = name
        self._age = age
    
    @property
    def age(self):
        return self._age
    
    @age.setter
    def age(self, value):
        if value < 0:
            raise ValueError('年齢は負の数にできません')
        self._age = value

person = Person('Alice', 30)
print(person.age)       # 30

person.age = 31
print(person.age)       # 31

# person.age = -5  # ValueError
```

## 複数の継承

```python
class Animal:
    def speak(self):
        print('Some sound')

class Swimmer:
    def swim(self):
        print('Swimming')

class Duck(Animal, Swimmer):
    pass

duck = Duck()
duck.speak()            # Some sound
duck.swim()             # Swimming
```

## 📌 重要なポイント

- **`__init__`**: コンストラクタ（初期化メソッド）
- **`self`**: インスタンス自身を指す
- **継承**: `class Child(Parent):`
- **`super()`**: 基底クラスのメソッドを呼び出す
- **オーバーライド**: 派生クラスで基底クラスのメソッドを上書き
- **プライベート**: `__`で始まる属性・メソッドはプライベート
- **`@property`**: ゲッター/セッターを簡潔に書ける
