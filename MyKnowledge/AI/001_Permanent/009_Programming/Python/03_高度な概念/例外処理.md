# 例外処理

## 概要

**例外**は、プログラムの実行中に発生するエラーです。適切に処理することで、プログラムのクラッシュを防げます。

## 基本的な例外処理

### try-except文

```python
try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f'ゼロ除算エラー: {e}')
# ゼロ除算エラー: division by zero
```

### 複数の例外を処理

```python
try:
    # いくつかの処理
    x = int('abc')  # ValueError
except ZeroDivisionError as e:
    print('ゼロ除算:', e)
except ValueError as e:
    print('値の変換エラー:', e)
except TypeError as e:
    print('型エラー:', e)

# 出力: 値の変換エラー: invalid literal for int() with base 10: 'abc'
```

### 複数の例外を一度に処理

```python
try:
    # 処理
    result = 10 / 0
except (ZeroDivisionError, ValueError) as e:
    print(f'エラーが発生しました: {e}')
```

### すべての例外を捕捉

```python
try:
    # 処理
    result = 10 / 0
except Exception as e:
    print(f'予期しないエラー: {type(e).__name__}: {e}')
```

## try-except-else-finally文

### else句：エラーが発生しなかった場合

```python
try:
    x = 10
    y = 2
    result = x / y
except ZeroDivisionError:
    print('ゼロ除算エラー')
else:
    print(f'計算成功: {result}')  # 出力される

# 出力: 計算成功: 5.0
```

### finally句：常に実行される処理

```python
try:
    file = open('data.txt', 'r')
    data = file.read()
except FileNotFoundError:
    print('ファイルが見つかりません')
finally:
    # ファイルの利用の有無に関わらず実行
    if 'file' in locals():
        file.close()
    print('終了します')
```

## 例外の送出（raise文）

### 標準例外を送出

```python
def set_age(age):
    if age < 0 or age > 150:
        raise ValueError('年齢は0から150の間である必要があります')
    return age

try:
    set_age(200)
except ValueError as e:
    print(f'エラー: {e}')

# エラー: 年齢は0から150の間である必要があります
```

### より詳細なエラーメッセージ

```python
def timestamp(hour, minute, second):
    if hour < 0 or 24 <= hour:
        raise ValueError('引数hourは0 <= hour < 24を満たす必要があります')
    if minute < 0 or 60 <= minute:
        raise ValueError('引数minuteは0 <= minute < 60を満たす必要があります')
    if second < 0 or 60 <= second:
        raise ValueError('引数secondは0 <= second < 60を満たす必要があります')
    return hour * 3600 + minute * 60 + second

try:
    timestamp(25, 0, 0)
except ValueError as e:
    print(f'入力エラー: {e}')
```

## カスタム例外

### 独自の例外クラスを定義

```python
# 基本的なカスタム例外
class TimestampError(Exception):
    pass

class InvalidHourError(TimestampError):
    pass

class InvalidMinuteError(TimestampError):
    pass

class InvalidSecondError(TimestampError):
    pass

def timestamp(hour, minute, second):
    if hour < 0 or 24 <= hour:
        raise InvalidHourError('引数hourは0 <= hour < 24を満たす必要があります')
    if minute < 0 or 60 <= minute:
        raise InvalidMinuteError('引数minuteは0 <= minute < 60を満たす必要があります')
    if second < 0 or 60 <= second:
        raise InvalidSecondError('引数secondは0 <= second < 60を満たす必要があります')
    return hour * 3600 + minute * 60 + second

# 使用例
try:
    timestamp(1, 95, 22)
except TimestampError as e:
    print(f'タイムスタンプエラー: {type(e).__name__}: {e}')
```

### 詳細なカスタム例外

```python
class BankAccountError(Exception):
    def __init__(self, message, balance, amount):
        super().__init__(message)
        self.balance = balance
        self.amount = amount

class InsufficientFundsError(BankAccountError):
    pass

class InvalidAmountError(BankAccountError):
    pass

def withdraw(balance, amount):
    if amount <= 0:
        raise InvalidAmountError(
            '引き出し額は正の数である必要があります',
            balance,
            amount
        )
    if amount > balance:
        raise InsufficientFundsError(
            f'残高不足です。残高: {balance}円',
            balance,
            amount
        )
    return balance - amount

# 使用例
try:
    new_balance = withdraw(1000, 2000)
except InsufficientFundsError as e:
    print(f'{e}')
    print(f'要求額: {e.amount}円')
```

## 一般的なPython例外

| 例外 | 説明 |
|---|---|
| `ValueError` | 不適切な値が渡された |
| `TypeError` | 予期しない型 |
| `ZeroDivisionError` | ゼロで除算 |
| `IndexError` | リストのインデックスが範囲外 |
| `KeyError` | 辞書のキーが存在しない |
| `FileNotFoundError` | ファイルが見つからない |
| `IOError` | 入出力エラー |
| `ImportError` | モジュールのインポート失敗 |
| `NameError` | 変数が定義されていない |
| `AttributeError` | 属性が存在しない |

## 例外処理のベストプラクティス

### 具体的な例外を処理

```python
# 良い例
try:
    file = open('data.txt')
except FileNotFoundError:
    print('ファイルが見つかりません')

# 避けるべき例
try:
    file = open('data.txt')
except Exception:
    print('何か問題が発生しました')
```

### 予測不可能なエラーに対応

```python
try:
    # リスク操作
    result = risky_function()
except SpecificError as e:
    # 既知のエラーに対応
    handle_known_error(e)
except Exception as e:
    # 予測不可能なエラーをログに記録
    log_error(e)
    raise  # 例外を再発生
```

## コンテキストマネージャー（with文）

```python
# 自動的にクリーンアップされる
with open('data.txt') as file:
    data = file.read()
    # 処理
# ファイルは自動的に閉じられる

# 複数のリソース
with open('input.txt') as infile, open('output.txt', 'w') as outfile:
    for line in infile:
        outfile.write(line.upper())
```

## 📌 重要なポイント

- **try-except**: 例外を処理する基本構文
- **複数の例外**: タプルで複数の例外型を指定可能
- **else**: 例外が発生しなかった場合に実行
- **finally**: 常に実行される（リソースの解放に使用）
- **raise**: 例外を送出する
- **カスタム例外**: 独自のException派生クラスを定義できる
- **with文**: コンテキストマネージャーで安全にリソースを管理
