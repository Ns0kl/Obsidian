# ファイル操作

## 概要

ファイルの読み書きと操作はプログラミングの基本的なタスクです。Pythonは使いやすいファイル操作のインターフェースを提供しています。

## ファイルの基本操作

### ファイルへの書き込み

```python
# 辞書データ
d = {
    '東京': ['とうきょう', 'Tokyo'],
    '神奈川': ['かながわ', 'Kanagawa'],
    '千葉': ['ちば', 'Chiba']
}

# ファイルへ書き込み
fo = open('./prefecture.txt', 'w', encoding='utf-8')
for ja, (yomi, en) in d.items():
    print(ja, yomi, en, file=fo)
fo.close()
```

### ファイルの読み込み

```python
# ファイル読込
with open('./prefecture.txt', encoding='utf-8') as fi:
    for line in fi:
        print(line, end='')
```

## ファイルオープンモード

| モード | 説明 |
|---|---|
| `'r'` | 読み込み（デフォルト） |
| `'w'` | 書き込み（上書き） |
| `'a'` | 追記 |
| `'x'` | 書き込み（ファイルが存在しないとき） |
| `'b'` | バイナリモード（`'rb'`, `'wb'`など） |
| `'+'` | 読み込みと書き込み（`'r+'`, `'w+'`など） |

```python
# 読み込みモード
file = open('data.txt', 'r')

# 書き込みモード（既存のファイルは削除される）
file = open('data.txt', 'w')

# 追記モード（ファイルの末尾に追加）
file = open('data.txt', 'a')

# バイナリ読み込み
file = open('image.jpg', 'rb')
```

## ファイルオブジェクトのメソッド

### read()：全体を読み込む

```python
with open('data.txt', 'r') as file:
    content = file.read()
    print(content)
    print(type(content))  # <class 'str'>
```

### readline()：1行読み込む

```python
with open('data.txt', 'r') as file:
    line1 = file.readline()
    line2 = file.readline()
    print(line1)
    print(line2)
```

### readlines()：すべての行をリストで読み込む

```python
with open('data.txt', 'r') as file:
    lines = file.readlines()
    # ['line1\n', 'line2\n', 'line3\n']
    for line in lines:
        print(line, end='')
```

### 行ごとの反復処理

```python
# 最も効率的な方法
with open('data.txt', 'r') as file:
    for line in file:
        print(line, end='')
```

### write()：書き込む

```python
with open('output.txt', 'w') as file:
    file.write('Hello\n')
    file.write('World\n')
```

### writelines()：複数行を書き込む

```python
lines = ['line1\n', 'line2\n', 'line3\n']
with open('output.txt', 'w') as file:
    file.writelines(lines)
```

## with文（コンテキストマネージャー）

```python
# with文を使う（推奨）
with open('data.txt', 'r') as file:
    content = file.read()
# with句を出たときにファイルが自動的に閉じられる

# open/closeを明示的に行う（非推奨）
file = open('data.txt', 'r')
try:
    content = file.read()
finally:
    file.close()
```

## テキストファイルの処理

### ファイルの読み込みと処理

```python
# 単語数をカウント
word_count = 0
with open('document.txt', 'r') as file:
    for line in file:
        words = line.split()
        word_count += len(words)
print(f'Total words: {word_count}')
```

### 行の置換と保存

```python
# ファイルの内容を読み込み
with open('input.txt', 'r') as file:
    lines = file.readlines()

# 置換
modified_lines = [line.replace('old', 'new') for line in lines]

# 結果を保存
with open('output.txt', 'w') as file:
    file.writelines(modified_lines)
```

## CSV ファイルの処理

### csvモジュールを使用

```python
import csv

# 読み込み
with open('data.csv', 'r') as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)  # リストとして返される

# 書き込み
data = [
    ['Name', 'Age', 'City'],
    ['Alice', '30', 'Tokyo'],
    ['Bob', '25', 'Osaka']
]

with open('output.csv', 'w', newline='') as file:
    writer = csv.writer(file)
    writer.writerows(data)
```

### DictReaderを使用（列名付き）

```python
import csv

with open('data.csv', 'r') as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(row)  # 辞書として返される
        # {'Name': 'Alice', 'Age': '30', 'City': 'Tokyo'}
```

## JSONファイルの処理

```python
import json

# Pythonオブジェクト → JSON
data = {
    'name': 'Alice',
    'age': 30,
    'city': 'Tokyo'
}

# ファイルに書き込み
with open('data.json', 'w') as file:
    json.dump(data, file, indent=2)

# ファイルから読み込み
with open('data.json', 'r') as file:
    loaded_data = json.load(file)
    print(loaded_data)

# JSON文字列 ↔ Pythonオブジェクト
json_string = json.dumps(data)           # Python → JSON文字列
python_object = json.loads(json_string)  # JSON文字列 → Python
```

## ファイルとディレクトリの操作

```python
import os
import pathlib

# ファイルの存在確認
print(os.path.exists('data.txt'))
print(pathlib.Path('data.txt').exists())

# ファイルサイズ
size = os.path.getsize('data.txt')
print(f'File size: {size} bytes')

# ファイルの削除
os.remove('temp.txt')

# ディレクトリ一覧
files = os.listdir('.')
for file in files:
    print(file)

# パスの操作
path = pathlib.Path('data/file.txt')
print(path.parent)       # data
print(path.name)         # file.txt
print(path.stem)         # file
print(path.suffix)       # .txt
```

## エンコーディング

```python
# 文字エンコーディングを指定
with open('data.txt', 'r', encoding='utf-8') as file:
    content = file.read()

with open('data.txt', 'r', encoding='shift_jis') as file:
    content = file.read()

# BOMなしUTF-8
with open('data.txt', 'r', encoding='utf-8-sig') as file:
    content = file.read()
```

## 📌 重要なポイント

- **with文**: ファイルの安全な自動クローズ
- **open()モード**: `'r'`, `'w'`, `'a'`を使い分ける
- **エンコーディング**: UTF-8を指定することが推奨される
- **readline() vs read()**: 大きなファイルはreadline()またはループが効率的
- **CSV/JSON**: 専用モジュールを使用する
- **例外処理**: ファイル操作時はFileNotFoundErrorなどに対応
