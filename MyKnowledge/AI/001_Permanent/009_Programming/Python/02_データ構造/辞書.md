# 辞書

## 概要

**辞書**は、キーと値のペアを持つ**ミュータブル**なデータ構造です。値は対応するキーで検索します。

## 辞書の基本

### 作成と型

```python
# キー:値 のペアで作成
d = {'東京': 'Tokyo', '神奈川': 'Kanagawa', '千葉': 'Chiba'}
print(d)
# {'東京': 'Tokyo', '神奈川': 'Kanagawa', '千葉': 'Chiba'}

print(type(d))  # <class 'dict'>
print(len(d))   # 3
```

### 空の辞書

```python
d = {}
d = dict()
```

## 値へのアクセス

### キーで値を取得

```python
d = {'東京': 'Tokyo', '神奈川': 'Kanagawa', '千葉': 'Chiba'}

# 通常のアクセス
print(d['東京'])  # 'Tokyo'

# キーが存在しないとKeyError
# print(d['富山'])  # KeyError
```

### get()メソッド（安全なアクセス）

```python
d = {'東京': 'Tokyo', '神奈川': 'Kanagawa', '千葉': 'Chiba'}

# キーが存在すれば値を返す
print(d.get('東京'))  # 'Tokyo'

# キーが存在しなければNoneを返す
print(d.get('富山'))  # None

# デフォルト値を指定
print(d.get('栃木', '不明'))  # '不明'
```

## キーの存在確認

```python
d = {'東京': 'Tokyo', '神奈川': 'Kanagawa', '千葉': 'Chiba'}

print('東京' in d)      # True
print('富山' in d)      # False
print('東京' not in d)  # False
```

## 要素の追加

```python
d = {'東京': 'Tokyo'}

# キーに値を代入（存在しなければ追加、存在すれば上書き）
d['神奈川'] = 'Kanagawa'
print(d)  # {'東京': 'Tokyo', '神奈川': 'Kanagawa'}

# 別の方法
d.update({'千葉': 'Chiba', '埼玉': 'Saitama'})
print(d)
# {'東京': 'Tokyo', '神奈川': 'Kanagawa', '千葉': 'Chiba', '埼玉': 'Saitama'}
```

## 要素の削除

```python
d = {'東京': 'Tokyo', '神奈川': 'Kanagawa', '千葉': 'Chiba'}

# キーを指定して削除
del d['神奈川']
print(d)  # {'東京': 'Tokyo', '千葉': 'Chiba'}

# pop()で削除して値を取得
value = d.pop('千葉')
print(value)  # 'Chiba'
print(d)      # {'東京': 'Tokyo'}

# キーが存在しなければデフォルト値を返す
value = d.pop('富山', '不明')
print(value)  # '不明'
```

## 辞書の反復処理

### キーで反復

```python
d = {'東京': 'Tokyo', '神奈川': 'Kanagawa'}

for key in d:
    print(key)
# 東京
# 神奈川
```

### 値で反復

```python
for value in d.values():
    print(value)
# Tokyo
# Kanagawa
```

### キーと値のペアで反復

```python
for key, value in d.items():
    print(f'{key}: {value}')
# 東京: Tokyo
# 神奈川: Kanagawa
```

## 辞書メソッド

```python
d = {'a': 1, 'b': 2, 'c': 3}

# すべてのキー
print(d.keys())          # dict_keys(['a', 'b', 'c'])

# すべての値
print(d.values())        # dict_values([1, 2, 3])

# すべてのキーと値のペア
print(d.items())         # dict_items([('a', 1), ('b', 2), ('c', 3)])

# 辞書をクリア
d_copy = d.copy()
d_copy.clear()
print(d_copy)            # {}
```

## 複雑な辞書構造

### ネストされた辞書

```python
person = {
    'name': 'Alice',
    'age': 30,
    'address': {
        'city': 'Tokyo',
        'zip': '100-0001'
    }
}

print(person['name'])                    # 'Alice'
print(person['address']['city'])         # 'Tokyo'
```

### 辞書のリスト

```python
students = [
    {'name': 'Alice', 'score': 85},
    {'name': 'Bob', 'score': 92},
    {'name': 'Charlie', 'score': 78}
]

for student in students:
    print(f'{student["name"]}: {student["score"]}')
```

## 辞書内包表記

```python
# 1から5の数値をキーとして、2乗を値とする辞書
squares = {x: x**2 for x in range(1, 6)}
print(squares)  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# 条件付き
evens = {x: x**2 for x in range(1, 11) if x % 2 == 0}
print(evens)    # {2: 4, 4: 16, 6: 36, 8: 64, 10: 100}
```

## キーの型と注意点

```python
# キーは変更不可のデータ型である必要がある
d = {
    'string': 'OK',
    42: 'number OK',
    (1, 2): 'tuple OK',
    # [1, 2]: 'list NG'  # TypeError
}

# リストは変更可能なので、キーにできない
# タプルは変更不可なので、キーにできる
```

## 📌 重要なポイント

- **キー**: 変更不可のデータ型（str, int, tuple等）
- **値**: 任何のデータ型
- **get()**: キーが存在しないときに安全
- **in演算子**: キーの存在確認
- **items()**: キーと値を同時に取得
- **ミュータブル**: 要素の追加・削除が可能
