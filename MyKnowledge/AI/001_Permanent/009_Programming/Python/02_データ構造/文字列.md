# 文字列

## 概要

**文字列**は、文字のシーケンスで、Pythonでは**イミュータブル**（変更不可）なデータ構造です。

## 文字列の基本

### 作成と型

```python
s = 'stress'
print(type(s))  # <class 'str'>
print(len(s))   # 6

# 空文字列
s = ''
s = str()
```

### 文字列リテラル

```python
# シングルクォート
s1 = 'Hello'

# ダブルクォート
s2 = "World"

# エスケープ
s3 = 'C:\\Users\\username'
print(s3)  # C:\Users\username

# シングルクォートを含む
s4 = "It's a beautiful day"
s5 = 'He said "Hello"'

# バックスラッシュでエスケープ
s6 = 'It\'s a beautiful day'
```

### 複数行文字列

```python
s = """最初の行
2行目
3行目"""

# または
s = '''最初の行
2行目
3行目'''
```

## 数値と文字列の変換

### 数値 → 文字列

```python
x = 42
s = str(x)           # '42'

pi = 3.14159
s = str(pi)          # '3.14159'
```

### 文字列 → 数値

```python
s = '42'
x = int(s)           # 42
x = int('ff', 16)    # 16進数: 255

s = '3.14'
f = float(s)         # 3.14
```

### 進法表記

```python
# 10進数を他の進法に変換
n = 255

bin(n)    # '0b11111111'    (2進数)
oct(n)    # '0o377'         (8進数)
hex(n)    # '0xff'          (16進数)

# 文字列を他の進法から変換
int('11111111', 2)   # 255 (2進数)
int('377', 8)        # 255 (8進数)
int('ff', 16)        # 255 (16進数)
```

## インデックスとスライス

```python
s = 'stressed'

# インデックス
print(s[0])      # 's'
print(s[-1])     # 'd'
print(s[3])      # 'e'

# スライス
print(s[0:3])    # 'str'
print(s[6:])     # 'ed'
print(s[-2:])    # 'ed'
print(s[::2])    # 'srse'（1個置き）
print(s[::-1])   # 'desserts'（逆順）
```

## 文字列操作

### 大文字・小文字変換

```python
s = "Hello World"

print(s.lower())    # 'hello world'
print(s.upper())    # 'HELLO WORLD'
print(s.capitalize()) # 'Hello world'
print(s.title())    # 'Hello World'
```

### 文字列の置換

```python
s = 'The quick brown fox jumps over the lazy dog'
s_replaced = s.replace('quick', 'slow')
print(s_replaced)   # 'The slow brown fox jumps over the lazy dog'

# 置換回数を制限
s_replaced = s.replace('o', '0', 2)  # 最初の2個だけ置換
```

### 検索

```python
s = 'https://www.example.com/path/to/page'

# 最初に現れる位置
idx = s.find('/')
print(idx)          # 6
print(s[:6])        # 'https:'

# 見つからない場合
idx = s.find('xyz')
print(idx)          # -1

# 最後に現れる位置
idx = s.rfind('/')
print(idx)          # 30
```

### 分割と連結

```python
s = 'apple,banana,orange'

# 分割
fruits = s.split(',')
print(fruits)       # ['apple', 'banana', 'orange']

# 連結
joined = ' - '.join(fruits)
print(joined)       # 'apple - banana - orange'

# 空文字で連結
print(''.join(['a', 'b', 'c']))  # 'abc'
```

### 空白の削除

```python
s = '  one, two, three, '

# 先頭と末尾から削除
s.strip(' ')        # 'one, two, three,'
s.strip(', ')       # 'one, two, three'

# 末尾から削除
s.rstrip(' ')       # '  one, two, three,'
s.rstrip(',')       # '  one, two, three'

# 先頭から削除
s.lstrip(' ')       # 'one, two, three, '
s.lstrip(', ')      # 'one, two, three, '
```

## 文字列の条件確認

```python
s = 'Tokyo Institute of Technology'

# 等式
print(s == 'TokyoTech')        # False

# 辞書順比較
print(s < 'Tokyo Tech')        # True
print(s > 'Tokyoaaaa')         # False

# 部分文字列を含むか
print('Institute' in s)        # True
print('University' not in s)   # True

# 指定した文字列で始まるか
print(s.startswith('Tokyo'))   # True
print(s.startswith('Tech'))    # False

# 指定した文字列で終わるか
print(s.endswith('Technology')) # True

# すべて大文字か
print('HELLO'.isupper())       # True
print('Hello'.isupper())       # False

# すべて小文字か
print('hello'.islower())       # True

# すべて数字か
print('12345'.isdigit())       # True
print('123a5'.isdigit())       # False
```

## 文字列のフォーマット

### f-string（Python 3.6以降）

```python
name = 'Alice'
age = 30

# 基本的なフォーマット
s = f'{name} is {age} years old'
print(s)  # 'Alice is 30 years old'

# 式の計算
x = 5
y = 10
print(f'Sum: {x + y}')        # 'Sum: 15'

# フォーマット指定
pi = 3.14159
print(f'{pi:.2f}')            # '3.14'
print(f'{1000000:,}')         # '1,000,000'
```

### str.format()

```python
s = '{0} is {1} years old'.format('Alice', 30)
print(s)  # 'Alice is 30 years old'

# キーワード引数
s = '{name} is {age} years old'.format(name='Bob', age=25)
```

### % フォーマット（古い方式）

```python
s = '%s is %d years old' % ('Charlie', 35)
print(s)  # 'Charlie is 35 years old'
```

## 📌 重要なポイント

- **イミュータブル**: 文字列は変更不可（置換は新しい文字列を作成）
- **インデックス**: リストと同じくマイナスインデックスに対応
- **スライス**: 部分文字列を効率的に取得
- **find() vs index()**: index()は見つからないとエラー
- **split() vs join()**: 逆の操作
- **f-string**: 最も読みやすく効率的なフォーマット方法
