# タプル

## 概要

**タプル**は、複数の要素を順序付きで保持する**イミュータブル**（変更不可）なデータ構造です。

## タプルの基本

### 作成と型

```python
# 括弧で作成
t = (0, 1, 4, 9, 16, 25, 36, 49)
print(t)        # (0, 1, 4, 9, 16, 25, 36, 49)
print(type(t))  # <class 'tuple'>

# 括弧なし（カンマで区切る）
t = 2, 4, 6
print(t)        # (2, 4, 6)

# 空のタプル
empty = ()
single = (1,)   # 要素が1つの場合はカンマが必須

# リストから変換
a = [1, 2, 3]
t = tuple(a)
print(t)        # (1, 2, 3)
```

## リストとタプルの違い

| 特性 | リスト | タプル |
|---|---|---|
| 型 | `list` | `tuple` |
| ミュータビリティ | ✅ 変更可能 | ❌ 変更不可 |
| 作成 | `[]` | `()` または `,` |
| 要素追加 | `append()` | 不可 |
| 要素削除 | `del`, `pop()` | 不可 |
| パフォーマンス | やや遅い | より高速 |
| 用途 | 動的データ | 固定データ |

## インデックスとスライス

```python
t = (0, 1, 4, 9, 16, 25, 36, 49)

# インデックスアクセス
print(t[0])      # 0
print(t[-1])     # 49
print(t[2])      # 4

# スライス
print(t[2:4])    # (4, 9)
print(t[:3])     # (0, 1, 4)
print(t[3:])     # (9, 16, 25, 36, 49)
print(t[::2])    # (0, 4, 16, 36)
```

## パック・アンパック

### パック（複数の値をタプルにする）

```python
t = 2, 4, 6      # (2, 4, 6)
print(t)

# 関数の戻り値
def get_coordinates():
    return 10, 20
point = get_coordinates()
print(point)     # (10, 20)
```

### アンパック（タプルを複数の変数に展開）

```python
t = (1, 3, 5)

# 1対1の対応
x, y, z = t
print(x, y, z)   # 1 3 5

# 値の交換
x = 10
y = 20
x, y = y, x
print(x, y)      # 20 10

# 複数の値を1つの変数に
a, *rest = (1, 2, 3, 4, 5)
print(a)         # 1
print(rest)      # [2, 3, 4, 5]

# 先頭と末尾のみを取得
first, *middle, last = (1, 2, 3, 4, 5)
print(first)     # 1
print(middle)    # [2, 3, 4]
print(last)      # 5
```

## タプルの操作

### インデックスの検索

```python
t = ('a', 'b', 'c', 'b', 'd')

# 最初に現れるインデックス
idx = t.index('b')
print(idx)       # 1

# 要素の個数
count = t.count('b')
print(count)     # 2
```

### 所属検査

```python
t = (1, 2, 3, 4, 5)

print(3 in t)       # True
print(6 not in t)   # True
```

## タプルとリストの相互変換

```python
# リスト → タプル
my_list = [1, 2, 3]
my_tuple = tuple(my_list)
print(my_tuple)     # (1, 2, 3)

# タプル → リスト
my_tuple = (1, 2, 3)
my_list = list(my_tuple)
print(my_list)      # [1, 2, 3]

# リストを変更してからタプルに
my_list[1] = 10
my_tuple = tuple(my_list)
print(my_tuple)     # (1, 10, 3)
```

## タプルの用途

### 関数の戻り値

```python
def get_user_info():
    return ('Alice', 30, 'Tokyo')

name, age, city = get_user_info()
print(name, age, city)  # Alice 30 Tokyo
```

### 辞書のキー

```python
# タプルは変更不可なので、辞書のキーに使える
locations = {
    (35.6762, 139.7674): 'Tokyo',
    (34.6937, 135.5023): 'Osaka'
}

print(locations[(35.6762, 139.7674)])  # 'Tokyo'
```

### リスト内包表記

```python
# 複数の値の組み合わせ
coordinates = [(x, y) for x in range(3) for y in range(3)]
print(coordinates)
# [(0, 0), (0, 1), (0, 2), (1, 0), (1, 1), (1, 2), (2, 0), (2, 1), (2, 2)]
```

## 📌 重要なポイント

- **イミュータブル**: 作成後は変更不可
- **高速**: リストより高速で安全
- **キーに使用可能**: 辞書やセットのキーに使える
- **パック・アンパック**: 複数の値を効率的に扱える
- **戻り値**: 関数から複数の値を返すのに便利
