# 集合

## 概要

**集合**は、順序のない**ユニークな要素**を持つ**ミュータブル**なデータ構造です。数学の集合演算に対応しています。

## 集合の基本

### 作成と型

```python
# 波括弧で作成
S = {'東京', '神奈川', '千葉', '埼玉'}
print(S)        # {'千葉', '埼玉', '東京', '神奈川'}（順序は保証されない）
print(type(S))  # <class 'set'>
print(len(S))   # 4

# set()コンストラクタで作成
S = set()       # 空の集合
S = set(['a', 'b', 'c'])  # リストから作成
print(S)        # {'a', 'b', 'c'}

# 重複する要素は自動的に削除される
S = set([1, 2, 2, 3, 3, 3])
print(S)        # {1, 2, 3}
```

### 空の集合の注意

```python
# これは空の集合ではなく、空の辞書
d = {}
print(type(d))  # <class 'dict'>

# 空の集合を作成するにはset()を使う
S = set()
print(type(S))  # <class 'set'>
```

## 要素の操作

### 要素の追加

```python
S = {'東京', '神奈川', '千葉'}

# 1つの要素を追加
S.add('埼玉')
print(S)        # {'東京', '神奈川', '千葉', '埼玉'}

# 既存の要素を追加しても何も起こらない
S.add('東京')
print(S)        # 変わらない

# 複数の要素を追加
S.update(['栃木', '群馬'])
print(S)        # {'東京', '神奈川', '千葉', '埼玉', '栃木', '群馬'}
```

### 要素の削除

```python
S = {'東京', '神奈川', '千葉', '埼玉'}

# remove()：要素を削除（存在しないとエラー）
S.remove('栃木')
# S.remove('群馬')  # KeyError

# discard()：要素を削除（存在しなくてもエラーなし）
S.discard('栃木')
print(S)        # 変わらない

S.discard('埼玉')
print(S)        # {'東京', '神奈川', '千葉'}

# pop()：ランダムに1つ削除して返す
element = S.pop()
print(element)  # ランダム
print(S)        # 1つ削除された

# clear()：すべての要素を削除
S_copy = S.copy()
S_copy.clear()
print(S_copy)   # set()
```

## 所属検査

```python
S = {'東京', '神奈川', '千葉'}

print('東京' in S)      # True
print('富山' in S)      # False
print('神奈川' not in S)  # False
```

## 集合演算

### 和集合（Union）

```python
A = {1, 2, 3}
B = {3, 4, 5}

# 2つの方法
print(A | B)           # {1, 2, 3, 4, 5}
print(A.union(B))      # {1, 2, 3, 4, 5}
```

### 交集合（Intersection）

```python
A = {1, 2, 3}
B = {3, 4, 5}

# 2つの方法
print(A & B)                    # {3}
print(A.intersection(B))        # {3}
```

### 差集合（Difference）

```python
A = {1, 2, 3}
B = {3, 4, 5}

# A にあってB にない要素
print(A - B)                    # {1, 2}
print(A.difference(B))          # {1, 2}
```

### 対称差（Symmetric Difference）

```python
A = {1, 2, 3}
B = {3, 4, 5}

# A と B のどちらかにあるが両方にはない要素
print(A ^ B)                    # {1, 2, 4, 5}
print(A.symmetric_difference(B))  # {1, 2, 4, 5}
```

## 集合の比較

### 部分集合と上位集合

```python
A = {1, 2, 3}
B = {1, 2}

# B は A の部分集合か？
print(B <= A)                   # True
print(B.issubset(A))            # True

# A は B の上位集合か？
print(A >= B)                   # True
print(A.issuperset(B))          # True

# 真部分集合（異なる要素があるか）
print(B < A)                    # True
print(A < A)                    # False
```

### 集合の等価性

```python
A = {1, 2, 3}
B = {3, 2, 1}
C = {1, 2}

print(A == B)                   # True（要素は同じ）
print(A == C)                   # False

# 交集合がない場合
A = {1, 2}
B = {3, 4}
print(A.isdisjoint(B))          # True
```

## 複数の集合演算

```python
A = {1, 2, 3}
B = {3, 4, 5}
C = {5, 6, 7}

# チェーンで実行
print(A | B | C)                # {1, 2, 3, 4, 5, 6, 7}
print(A & B & C)                # set()
print((A | B) & C)              # {5}
```

## 集合と更新演算

```python
A = {1, 2, 3}
B = {3, 4, 5}

# 和集合で更新
A |= B
print(A)                        # {1, 2, 3, 4, 5}

# 交集合で更新
A = {1, 2, 3}
A &= B
print(A)                        # {3}

# 差集合で更新
A = {1, 2, 3}
A -= B
print(A)                        # {1, 2}

# 対称差で更新
A = {1, 2, 3}
A ^= B
print(A)                        # {1, 2, 4, 5}
```

## 集合の用途

### 重複排除

```python
numbers = [1, 2, 2, 3, 3, 3, 4]
unique = list(set(numbers))
print(unique)                   # [1, 2, 3, 4]（順序は保証されない）
```

### 要素の高速検索

```python
# リストでの検索：O(n)
large_list = list(range(1000000))
print(500 in large_list)        # 遅い

# 集合での検索：O(1)
large_set = set(range(1000000))
print(500 in large_set)         # 高速
```

### 集合演算

```python
registered = {'Alice', 'Bob', 'Charlie'}
attended = {'Alice', 'Charlie', 'David'}

# 出席しなかった登録ユーザー
not_attended = registered - attended
print(not_attended)             # {'Bob'}

# 登録していない出席者
unregistered = attended - registered
print(unregistered)             # {'David'}

# 登録して出席した者
both = registered & attended
print(both)                     # {'Alice', 'Charlie'}
```

## 📌 重要なポイント

- **ユニーク**: 重複した要素は自動的に削除される
- **順序なし**: 要素の順序は保証されない
- **高速検索**: `in`演算子が高速（O(1)）
- **ミュータブル**: 作成後に要素を追加・削除できる
- **集合演算**: 数学的な集合演算に対応している
- **ハッシュ可能**: 要素はハッシュ可能である必要がある
