## よくある学習の落とし穴

### 1. **リストと参照の混乱**

❌ **悪い例**:
```python
my_list = [1, 2, 3]
copy = my_list
copy.append(4)
print(my_list)  # [1, 2, 3, 4] 意図しない変更
```

✅ **良い例**:
```python
my_list = [1, 2, 3]
copy = my_list.copy()  # コピーを作成
copy.append(4)
print(my_list)  # [1, 2, 3]
```

参照：[[03_高度な概念/可変・不変]]

### 2. **例外をキャッチしない**

❌ **悪い例**:
```python
file = open('data.txt')
content = file.read()
file.close()
```

✅ **良い例**:
```python
try:
    with open('data.txt') as file:
        content = file.read()
except FileNotFoundError:
    print('ファイルが見つかりません')
```

参照：[[03_高度な概念/例外処理]]

### 3. **全ての例外を同じように処理**

❌ **悪い例**:
```python
try:
    # 何かの処理
    pass
except:  # すべての例外
    print('エラーが発生しました')
```

✅ **良い例**:
```python
try:
    # 何かの処理
    pass
except ZeroDivisionError:
    print('ゼロで除算しました')
except ValueError:
    print('値が正しくありません')
except Exception as e:
    print(f'予期しないエラー: {e}')
```

### 4. **スライスと元のデータの混乱**

❌ **悪い例**:
```python
numbers = [1, 2, 3, 4, 5]
subset = numbers[1:3]  # [2, 3]
subset.append(10)
print(numbers)  # [1, 2, 3, 4, 5] スライスはコピー
```

✅ **理解すべき点**:
```python
numbers = [1, 2, 3, 4, 5]
subset = numbers[1:3]  # スライスは新しいリスト
# 元のリストに影響しない
```

## プロジェクト実例

### 小規模プロジェクト案

#### 1. **計算機プログラム**
学習内容：関数、制御文、例外処理

```python
def calculator(operation, x, y):
    if operation == '+':
        return x + y
    elif operation == '-':
        return x - y
    elif operation == '*':
        return x * y
    elif operation == '/':
        if y == 0:
            raise ValueError('ゼロで除算できません')
        return x / y
    else:
        raise ValueError('不正な操作')
```

#### 2. **ファイル処理**
学習内容：ファイル操作、リスト、辞書

```python
def analyze_csv(filename):
    with open(filename, 'r') as f:
        lines = f.readlines()
    data = [line.strip().split(',') for line in lines[1:]]
    return data
```

#### 3. **クラスベースのプログラム**
学習内容：クラス、継承、例外処理

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def __str__(self):
        return f'{self.name} ({self.age})'
```

## よくある質問

### Q: Pythonはなぜ人気なのか？

A: Pythonは以下の理由で人気があります：
- **読みやすい**: 初心者にも理解しやすい文法
- **多機能**: Webアプリ、データ分析、機械学習など幅広い用途
- **豊富なライブラリ**: NumPy、Pandas、Django等
- **大規模コミュニティ**: 情報や支援が豊富

### Q: 学習にはどのくらい時間がかかる？

A: 目標によって異なります：
- **基本**: 1-2ヶ月（日1-2時間）
- **実務レベル**: 3-6ヶ月（日3-4時間）
- **エキスパート**: 1-2年（継続的な学習）

### Q: 習った後、何をすべき？

A: 
1. **実践的なプロジェクト**を作成
2. **オープンソース**に貢献
3. **認定資格**を取得（オプション）
4. **フレームワーク**（Django, FastAPI等）を学ぶ
5. **データ分析**や**機械学習**に進む
