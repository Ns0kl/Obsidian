# 定数の定義

## 概要

**定数**は、プログラム実行中に値が変わらないデータです。Pythonでは慣習と`typing.Final`を用いて定数を定義します。

## 定数命名規則

Pythonでは、定数は**大文字と下線**で表記する慣習があります：

```python
# 定数
MAX_SIZE = 100
MIN_VALUE = 0
DEFAULT_TIMEOUT = 30
API_KEY = 'secret_key_value'
```

## Final型アノテーション

Python 3.8以降では、`typing.Final`を使って定数を明示的に定義できます：

```python
from typing import Final

# 単純な定数
EXAMPLE: Final[str] = 'example'
MAX_ATTEMPTS: Final[int] = 5
PI: Final[float] = 3.14159
```

### 読み取り専用の保証

`Final`を使うと、IDEやリンターが変更をトラップできます：

```python
from typing import Final

CONSTANT: Final[str] = 'value'

# これはエラーとして認識される（実行時には発生しない）
# CONSTANT = 'new_value'  # mypy: error
```

## タプルとリストの定数

### 不変タプル

```python
from typing import Final

# タプルなので変更不可
EXAMPLE_TUPLE: Final[tuple[str, str]] = ('example_1', 'example_2')

# これはエラー
# EXAMPLE_TUPLE[0] = 'new_value'  # TypeError
```

### リスト（注意）

```python
from typing import Final

# リストは変更可能（値の再代入は防ぐが、要素は変更可能）
EXAMPLE_LIST: Final[list[str]] = ['example_1', 'example_2']

# 値の再代入はエラー
# EXAMPLE_LIST = ['new_value']  # 型チェッカーがエラーを検出

# ただし、要素の変更は可能（推奨されない）
EXAMPLE_LIST[0] = 'modified'  # これは可能（非推奨）
print(EXAMPLE_LIST)  # ['modified', 'example_2']
```

### リストを真に不変にする

```python
from typing import Final

# タプルを使って完全に不変にする
IMMUTABLE_LIST: Final[tuple[str, ...]] = ('example_1', 'example_2', 'example_3')

# これはエラー
# IMMUTABLE_LIST[0] = 'new_value'  # TypeError
# IMMUTABLE_LIST = []  # 型チェッカーがエラーを検出
```

## モジュールレベルの定数

```python
# constants.py
from typing import Final

# グローバル定数
DATABASE_URL: Final[str] = 'postgresql://localhost/mydb'
DEBUG_MODE: Final[bool] = False
MAX_CONNECTIONS: Final[int] = 100
ALLOWED_HOSTS: Final[tuple[str, ...]] = ('localhost', '127.0.0.1')
```

### 定数モジュールの使用

```python
import constants

print(constants.DATABASE_URL)
print(constants.MAX_CONNECTIONS)
```

## クラス内の定数

```python
from typing import Final

class DatabaseConfig:
    # クラス定数
    DEFAULT_PORT: Final[int] = 5432
    DEFAULT_TIMEOUT: Final[int] = 30
    
    def __init__(self, host: str):
        self.host = host
    
    def get_connection_string(self) -> str:
        return f'{self.host}:{self.DEFAULT_PORT}'

config = DatabaseConfig('localhost')
print(config.DEFAULT_PORT)  # 5432
```

## 列挙型を使った定数管理

```python
from enum import Enum

class Status(Enum):
    PENDING = 'pending'
    APPROVED = 'approved'
    REJECTED = 'rejected'
    COMPLETED = 'completed'

# 使用
status = Status.APPROVED
print(status)           # Status.APPROVED
print(status.value)     # 'approved'
print(status.name)      # 'APPROVED'

# 比較
if status == Status.APPROVED:
    print('承認されました')
```

### 数値の列挙

```python
from enum import Enum

class Priority(Enum):
    LOW = 1
    MEDIUM = 2
    HIGH = 3
    CRITICAL = 4

# 使用
priority = Priority.HIGH
print(priority.value)  # 3
```

## 環境変数から定数を読み込む

```python
import os
from typing import Final

# 環境変数から定数を取得
API_KEY: Final[str] = os.getenv('API_KEY', 'default_key')
DEBUG: Final[bool] = os.getenv('DEBUG', 'False').lower() == 'true'
MAX_RETRIES: Final[int] = int(os.getenv('MAX_RETRIES', '3'))

print(API_KEY)
print(DEBUG)
print(MAX_RETRIES)
```

## dataclassを使った定数グループ

```python
from dataclasses import dataclass
from typing import Final

@dataclass(frozen=True)
class AppConfig:
    APP_NAME: str = 'MyApp'
    VERSION: str = '1.0.0'
    DEBUG: bool = False
    MAX_SIZE: int = 1000

config = AppConfig()
print(config.APP_NAME)

# frozen=Trueなので変更不可
# config.VERSION = '2.0.0'  # dataclasses.FrozenInstanceError
```

## 📌 重要なポイント

- **命名規則**: 定数は大文字で定義
- **Final型**: `typing.Final`で定数性を明示
- **タプルVSリスト**: 真に不変なら`tuple`を使用
- **リスト要素**: `Final[list]`でも要素は変更可能（注意）
- **列挙型**: 関連する定数をグループ化するときに便利
- **環境変数**: デプロイ環境に応じて値を変える場合に使用
