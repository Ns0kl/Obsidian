# 変数と型

## 概要

Pythonにおける**変数**は、値を保存するための名前付きの場所です。Pythonは**動的型言語**であり、変数の型は実行時に決まります。

## 変数の基本

### 変数の宣言と初期化

```python
x = 3
print(type(x))  # <class 'int'>

y = "hello"
print(type(y))  # <class 'str'>

z = 3.14
print(type(z))  # <class 'float'>
```

Pythonでは変数を先に宣言する必要はなく、値を代入すると同時に変数が作成されます。

### 型のアノテーション

変数の型をあらかじめ示すことができます（実行に影響しません）:

```python
x: int = 5
name: str = "Alice"
price: float = 19.99
```

## 基本的なデータ型

| 型 | 例 | 説明 |
|---|---|---|
| `int` | `42`, `-5` | 整数 |
| `float` | `3.14`, `1.0` | 浮動小数点数 |
| `str` | `"hello"`, `'world'` | 文字列 |
| `bool` | `True`, `False` | 論理値 |
| `list` | `[1, 2, 3]` | 可変シーケンス |
| `dict` | `{"key": "value"}` | キーバリューマッピング |

## 型の変換

### 文字列から数値への変換

```python
# 文字列 → 数値
num_str = "42"
num_int = int(num_str)       # 42
num_float = float("3.14")    # 3.14

# 数値 → 文字列
x = 42
s = str(x)                   # "42"
```

### 数値の異なる進法表現

```python
# 10進数を16進数に
hex(255)   # '0xff'

# 10進数を2進数に
bin(255)   # '0b11111111'

# 8進数
oct(255)   # '0o377'
```

## 変数の削除

```python
x = 42
del x
# print(x)  # NameError: name 'x' is not defined
```

`del`文を使って変数をメモリから削除することができます。削除後にその変数を参照するとエラーが発生します。

## 📌 重要なポイント

- **動的型**: Pythonは変数の型を実行時に決めます
- **型変換**: `int()`, `str()`, `float()`などで型を変換できます
- **型チェック**: `type()`関数で変数の型を確認できます
- **型アノテーション**: 可読性を高めるために型をコメントとして追加できます
