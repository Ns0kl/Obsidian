# 演算と計算

## 概要

Pythonの演算子を使用して、数値や他のデータ型に対して様々な操作を実行できます。

## 算術演算子

### 基本的な四則演算

```python
# 加算
print(9 + 2)   # 11

# 減算
print(9 - 2)   # 7

# 乗算
print(9 * 2)   # 18

# 除算（浮動小数点数を返す）
print(9 / 2)   # 4.5

# 整数除算（整数を返す）
print(9 // 2)  # 4

# 剰余算（余りを返す）
print(9 % 2)   # 1

# 累乗
print(9 ** 2)  # 81
```

### 演算子の優先順位

Pythonは数学の規則に従います：
1. `**` （累乗）
2. `*`, `/`, `//`, `%` （乗除）
3. `+`, `-` （加減）

```python
2 + 3 * 4      # 14 (* が先に実行される)
(2 + 3) * 4    # 20 (括弧で優先順位を変更)
2 ** 3 ** 2    # 512 (** は右結合)
```

## 浮動小数点数の特殊形式

```python
# 指数表記
print(6.02e23)   # 6.02 × 10^23
print(1e-4)      # 0.0001

# 負の数の演算
print(-9.0 + 2)  # -7.0
print(-9 // 2)   # -5.0 (注意: 床関数の動作)
```

## 比較演算子

```python
x = 10
y = 20

print(x == y)    # False  等しい
print(x != y)    # True   等しくない
print(x < y)     # True   より小さい
print(x <= y)    # True   以下
print(x > y)     # False  より大きい
print(x >= y)    # True   以上
```

## 論理演算子

```python
# and: 両方がTrueのときTrue
print(True and True)    # True
print(True and False)   # False

# or: どちらかがTrueのときTrue
print(True or False)    # True
print(False or False)   # False

# not: 論理値を反転
print(not True)         # False
print(not False)        # True

# 複合条件
x = 37.1
if 37.0 <= x and x <= 37.5:
    print('微熱がある')
```

## in演算子と所属検査

```python
# リストやタプルに要素が含まれているか確認
n = 4
print(n in (2, 4, 6, 8))      # True
print(n not in (2, 4, 6, 8))  # False

# 文字列が含まれているか
print('a' in 'apple')         # True
```

## 代入演算子

```python
x = 10

# 複合代入演算子
x += 5    # x = x + 5   → 15
x -= 3    # x = x - 3   → 12
x *= 2    # x = x * 2   → 24
x /= 4    # x = x / 4   → 6.0
x %= 5    # x = x % 5   → 1
```

## 三項演算子（条件演算子）

```python
m = 5
result = '偶数' if m % 2 == 0 else '奇数'
print(result)  # '奇数'

# 複数の条件
age = 18
status = '成人' if age >= 18 else '未成年'
```

## 📌 重要なポイント

- **整数除算 (`//`)**: 結果が常に整数（床関数）
- **剰余算 (`%`)**: 負の数での動作に注意
- **累乗の結合**: `2 ** 3 ** 2` は `2 ** (3 ** 2)` = 512
- **優先順位**: 括弧で明示的に指定することが推奨される
- **論理演算**: Pythonの`and`と`or`は短絡評価を行う
