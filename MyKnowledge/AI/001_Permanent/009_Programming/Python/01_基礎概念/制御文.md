# 制御文

## 概要

制御文は、プログラムの実行フローを制御します。条件によって異なるコードを実行したり、繰り返し処理を行います。

## if文（条件分岐）

### 基本形

```python
x = 37.1

if 37.5 <= x:
    print('熱がある')
elif 37.0 <= x:
    print('微熱がある')
else:
    print('熱はない')
```

### 複合条件

```python
y = 10

# and演算子
if y >= 0 and y <= 100:
    print('0〜100の範囲内')

# or演算子
if y < 0 or y > 100:
    print('範囲外')

# not演算子
if not y < 100:
    print('100以上')
```

### in演算子による所属検査

```python
n = 4
if n in (2, 4, 6, 8):
    print('偶数')
```

## 三項演算子（条件演算子）

```python
m = 5
result = '偶数' if m % 2 == 0 else '奇数'
print(result)  # '奇数'
```

## for文（反復処理）

### 基本形

```python
# range()を使った反復
for i in range(10):
    print('W', end='')  # 改行を抑制
    print(i, 10 * i)

# 出力:
# W0 0
# W1 10
# W2 20
# ...
```

### rangeの使い方

```python
# range(stop)
for i in range(5):           # 0, 1, 2, 3, 4
    print(i, end=' ')

# range(start, stop)
for i in range(1, 10):       # 1, 2, ..., 9
    print(i, end=' ')

# range(start, stop, step)
for i in range(1, 10, 2):    # 1, 3, 5, 7, 9
    print(i, end=' ')

# 逆順
for i in range(10, 0, -1):   # 10, 9, ..., 1
    print(i, end=' ')
```

### リストやシーケンスの反復

```python
weekdays = ['monday', 'tuesday', 'wednesday', 'thursday', 'friday']

for day in weekdays:
    print(day)

# インデックス付きで反復
for i, day in enumerate(weekdays):
    print(f'{i}: {day}')
```

## while文（条件付き繰り返し）

```python
# 基本形
count = 0
while count < 5:
    print(count)
    count += 1

# 複雑な例：コラッツの問題
l = 36
while l != 1:
    if l % 2 == 0:
        l = l // 2
    else:
        l = 3 * l + 1
    print(l, end=' ')  # 18 9 28 14 7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

## break文（ループの途中終了）

```python
# Newton-Raphson法（平方根計算）
x = 1
while True:
    fx = x ** 2 - 2
    gx = 2 * x
    print(x, fx)
    
    if -1e-8 < fx < 1e-8:  # 十分に近い値
        break  # ループを終了
    
    x -= fx / gx
```

## continue文（ループの次の反復へ）

```python
# 素数でない数の約数を表示
N = 10
for n in range(2, N + 1):
    for a in range(2, n // 2 + 1):
        if n % a == 0:
            print(f'{n} = {a} * {n//a}')
            break
        else:
            continue  # 次の値を試す
```

## ループの制御パターン

### else句付きのループ

```python
# ループが正常に終了したときにelseが実行される
for i in range(5):
    if i == 10:  # 実行されない
        break
else:
    print('ループが完了')  # 実行される
```

### ネストされたループ

```python
# 2次元配列の走査
for i in range(3):
    for j in range(3):
        print(f'({i}, {j})', end=' ')
    print()  # 改行
```

## 📌 重要なポイント

- **if/elif/else**: 複数の条件を処理できる
- **for**: 反復可能なオブジェクト（list, tuple, str等）を走査
- **while**: 条件がTrueの間、繰り返す
- **break**: 最も内側のループのみを終了
- **continue**: 現在の反復をスキップして次に進む
- **インデント**: Pythonではインデントが構造を定義する
