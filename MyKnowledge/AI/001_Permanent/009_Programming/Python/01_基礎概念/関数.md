# 関数

## 概要

**関数**は、再利用可能なコードのブロックです。特定のタスクを実行し、結果を返します。

## 関数の定義と呼び出し

### 基本形

```python
# 関数の定義
def greet():
    print('Hello!')

# 関数の呼び出し
greet()  # Hello!
```

### パラメータと戻り値

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 8
```

### 複数の戻り値

```python
def divmod_custom(a, b):
    quotient = a // b
    remainder = a % b
    return quotient, remainder  # タプルで複数の値を返す

q, r = divmod_custom(17, 5)
print(q, r)  # 3 2
```

## パラメータの種類

### デフォルト値

```python
def power(x, n=2):
    return x ** n

print(power(3))      # 9     (n=2)
print(power(3, 3))   # 27    (n=3)
```

### 位置引数とキーワード引数

```python
def set_info(name, age, city='Tokyo'):
    print(f'{name}, {age}, {city}')

set_info('Alice', 30)                    # Alice, 30, Tokyo
set_info('Bob', 25, 'Osaka')             # Bob, 25, Osaka
set_info(age=28, name='Charlie')         # Charlie, 28, Tokyo
```

## 可変長引数

### *args: 任意個数の位置引数

```python
def decimal(*args):
    v = 0
    for arg in args:
        v = v * 10 + arg
    print(type(args), repr(args))  # <class 'tuple'> (arg[0], arg[1], ...)
    return v

result = decimal(1, 2, 3, 4)
print(result)  # 1234
```

### **kwargs: 任意個数のキーワード引数

```python
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f'{key}: {value}')

print_info(name='Alice', age=30, city='Tokyo')
# name: Alice
# age: 30
# city: Tokyo
```

### 組み合わせ

```python
def combine_args(a, b, *args, **kwargs):
    print(f'a={a}, b={b}')
    print(f'args={args}')
    print(f'kwargs={kwargs}')

combine_args(1, 2, 3, 4, x=10, y=20)
# a=1, b=2
# args=(3, 4)
# kwargs={'x': 10, 'y': 20}
```

## スコープと変数

### ローカルスコープとグローバルスコープ

```python
x = 100  # グローバル変数

def change_x():
    x = 50  # ローカル変数
    print(x)  # 50

change_x()
print(x)  # 100 (グローバル変数は変わっていない)

def change_global():
    global x
    x = 75  # グローバル変数を変更

change_global()
print(x)  # 75
```

## 関数型プログラミング

### ラムダ関数

```python
# 単純な関数
square = lambda x: x ** 2
print(square(5))  # 25

# 複数の引数
add = lambda x, y: x + y
print(add(3, 4))  # 7
```

### map, filter, sorted

```python
numbers = [1, 2, 3, 4, 5]

# map: 各要素に関数を適用
squared = list(map(lambda x: x ** 2, numbers))
print(squared)  # [1, 4, 9, 16, 25]

# filter: 条件に合う要素をフィルタリング
evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)  # [2, 4]

# sorted: キーを指定してソート
words = ['apple', 'pie', 'zoo', 'cat']
sorted_by_len = sorted(words, key=lambda x: len(x))
print(sorted_by_len)  # ['pie', 'cat', 'zoo', 'apple']
```

## 関数のベストプラクティス

### ドキュメンテーション

```python
def factorial(n):
    \"\"\"
    与えられた数の階乗を計算する。
    
    Args:
        n (int): 階乗を計算する正の整数
    
    Returns:
        int: n の階乗
    \"\"\"
    if n == 0:
        return 1
    return n * factorial(n - 1)
```

### 型ヒント

```python
def add(x: int, y: int) -> int:
    return x + y

def greet(name: str) -> str:
    return f'Hello, {name}!'
```

## 📌 重要なポイント

- **def**: 関数を定義するキーワード
- **return**: 関数から値を返す
- **スコープ**: 関数内の変数はローカルスコープを持つ
- **デフォルト値**: 引数にデフォルト値を設定できる
- ***args**: 任意個数の位置引数を受け取る
- ****kwargs**: 任意個数のキーワード引数を受け取る
- **ラムダ**: 無名関数を作成できる
