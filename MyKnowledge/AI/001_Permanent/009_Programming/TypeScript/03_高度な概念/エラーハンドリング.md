# エラーハンドリング

## 概要

**エラーハンドリング**は、プログラムの予期しない状況に対応する重要な技術です。TypeScriptではJavaScriptの例外処理を活用します。

## try・catch・finally

### 基本形

```typescript
try {
    // 実行するコード
    const result: number = JSON.parse("invalid json");
} catch (error) {
    // エラーが発生した場合の処理
    console.log("エラーが発生しました");
}
```

### エラーオブジェクト

```typescript
try {
    throw new Error("Something went wrong");
} catch (error) {
    // errorはunknown型
    if (error instanceof Error) {
        console.log(error.message);  // "Something went wrong"
        console.log(error.name);     // "Error"
        console.log(error.stack);    // スタックトレース
    }
}
```

### finally句

```typescript
try {
    console.log("処理を実行");
    throw new Error("エラー発生");
} catch (error) {
    console.log("エラーを処理");
} finally {
    // 常に実行される
    console.log("終了処理");
}

// 出力:
// 処理を実行
// エラーを処理
// 終了処理
```

## 複数の例外処理

### 異なる例外タイプ

```typescript
try {
    const arr: number[] = [1, 2, 3];
    const result: number = arr[10] * 2;  // undefinedでNaN
    
    if (isNaN(result)) {
        throw new RangeError("インデックスが範囲外です");
    }
} catch (error) {
    if (error instanceof RangeError) {
        console.log("範囲エラー:", error.message);
    } else if (error instanceof TypeError) {
        console.log("型エラー:", error.message);
    } else if (error instanceof Error) {
        console.log("一般的なエラー:", error.message);
    } else {
        console.log("不明なエラー:", error);
    }
}
```

### エラー型ガード

```typescript
function handleError(error: unknown): void {
    if (error instanceof Error) {
        console.log(error.message);
    } else if (typeof error === 'string') {
        console.log(error);
    } else if (error && typeof error === 'object' && 'message' in error) {
        console.log((error as { message: string }).message);
    } else {
        console.log("未知のエラー:", error);
    }
}

handleError(new Error("Error message"));
handleError("String error");
handleError({ message: "Custom error" });
```

## カスタム例外クラス

```typescript
class ValidationError extends Error {
    constructor(
        message: string,
        public field: string
    ) {
        super(message);
        this.name = "ValidationError";
    }
}

class AuthenticationError extends Error {
    constructor(message: string) {
        super(message);
        this.name = "AuthenticationError";
    }
}

try {
    if (!email.includes("@")) {
        throw new ValidationError("無効なメールアドレス", "email");
    }
} catch (error) {
    if (error instanceof ValidationError) {
        console.log(`フィールド ${error.field}: ${error.message}`);
    }
}
```

## throw文

```typescript
function divide(a: number, b: number): number {
    if (b === 0) {
        throw new Error("ゼロで除算することはできません");
    }
    return a / b;
}

try {
    const result: number = divide(10, 0);
} catch (error) {
    if (error instanceof Error) {
        console.log(error.message);
    }
}

// 値をそのままthrowも可（非推奨）
try {
    throw "エラー文字列";
} catch (error) {
    console.log(error);  // "エラー文字列"
}
```

## Promise でのエラーハンドリング

```typescript
function fetchData(url: string): Promise<string> {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            if (url.includes("error")) {
                reject(new Error("ネットワークエラー"));
            } else {
                resolve("データ取得成功");
            }
        }, 1000);
    });
}

// .catch() でハンドリング
fetchData("https://api.example.com/data")
    .then((data: string) => console.log(data))
    .catch((error: Error) => console.log(error.message));

// 複数のcatch
fetchData("https://api.example.com/error")
    .then((data: string) => console.log(data))
    .catch((error: Error) => {
        if (error.message.includes("ネットワーク")) {
            console.log("ネットワークエラー対応");
        } else {
            console.log("その他のエラー対応");
        }
    });
```

## async/await でのエラーハンドリング

```typescript
async function loadData(url: string): Promise<string> {
    try {
        const response: Response = await fetch(url);
        if (!response.ok) {
            throw new Error(`HTTP ${response.status}: ${response.statusText}`);
        }
        return await response.text();
    } catch (error) {
        if (error instanceof Error) {
            console.log("エラー:", error.message);
        }
        throw error;  // 呼び出し元に伝播
    }
}

// 呼び出し側
(async () => {
    try {
        const data: string = await loadData("https://api.example.com/data");
        console.log(data);
    } catch (error) {
        console.log("データ取得に失敗しました");
    }
})();
```

## APIレスポンスのエラーハンドリング

```typescript
interface ApiResponse<T> {
    success: boolean;
    data?: T;
    error?: {
        code: string;
        message: string;
    };
}

async function fetchUserData(userId: number): Promise<{ id: number; name: string }> {
    const response: Response = await fetch(`/api/users/${userId}`);
    const result: ApiResponse<{ id: number; name: string }> = await response.json();

    if (!result.success) {
        throw new Error(result.error?.message || "Unknown error");
    }

    if (!result.data) {
        throw new Error("No data returned");
    }

    return result.data;
}
```

## デフォルト値でのエラー処理

```typescript
function safeParse<T>(json: string, defaultValue: T): T {
    try {
        return JSON.parse(json);
    } catch {
        console.log("パース失敗、デフォルト値を使用");
        return defaultValue;
    }
}

const data = safeParse('{"invalid json}', { name: "Unknown" });
console.log(data);  // { name: "Unknown" }
```

## Optional Chaining と Nullish Coalescing

```typescript
interface User {
    profile?: {
        address?: {
            zip?: string;
        };
    };
}

const user: User = {};

// Optional Chaining：nullやundefinedの場合はundefinedを返す
const zip: string | undefined = user.profile?.address?.zip;
console.log(zip);  // undefined（エラーにならない）

// Nullish Coalescing：nullやundefinedの場合はデフォルト値
const zipCode: string = user.profile?.address?.zip ?? "Unknown";
console.log(zipCode);  // "Unknown"
```

## バリデーション関数

```typescript
interface ValidationResult {
    isValid: boolean;
    errors: string[];
}

function validateUser(user: {
    name?: string;
    email?: string;
    age?: number;
}): ValidationResult {
    const errors: string[] = [];

    if (!user.name || user.name.trim() === "") {
        errors.push("名前は必須です");
    }

    if (!user.email || !user.email.includes("@")) {
        errors.push("有効なメールアドレスを入力してください");
    }

    if (!user.age || user.age < 0 || user.age > 150) {
        errors.push("年齢は0〜150の間で指定してください");
    }

    return {
        isValid: errors.length === 0,
        errors
    };
}

const result: ValidationResult = validateUser({ name: "Alice", email: "invalid" });
if (!result.isValid) {
    result.errors.forEach(error => console.log(`- ${error}`));
}
```

## 📌 重要なポイント

- **try/catch/finally**: 例外処理の基本
- **Error クラス**: メッセージとスタックトレースを持つ
- **カスタム例外**: 固有のエラータイプを定義
- **型ガード**: errorの型をチェック
- **async/await**: Promiseのエラーをtry/catchで処理
- **Optional Chaining**: nullチェックを簡潔に
