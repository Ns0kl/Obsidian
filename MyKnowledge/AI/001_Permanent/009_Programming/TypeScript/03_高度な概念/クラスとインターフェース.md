# クラスとインターフェース

## 概要

**クラス**は、オブジェクト指向プログラミングの基本です。TypeScriptは**インターフェース**で型定義と契約を実現します。

## クラスの基本

### クラス定義

```typescript
class Dog {
    name: string;
    age: number;

    constructor(name: string, age: number) {
        this.name = name;
        this.age = age;
    }

    bark(): void {
        console.log(`${this.name} says Woof!`);
    }

    getInfo(): string {
        return `${this.name} is ${this.age} years old`;
    }
}

// インスタンス化
const dog: Dog = new Dog("Buddy", 3);
console.log(dog.getInfo());  // "Buddy is 3 years old"
dog.bark();                  // "Buddy says Woof!"
```

### プロパティの初期化

```typescript
// パラメータプロパティ（簡潔な記法）
class Person {
    constructor(
        public name: string,
        public age: number,
        private ssn: string
    ) {}

    displayInfo(): void {
        console.log(`${this.name}, ${this.age}`);
    }
}

const person: Person = new Person("Alice", 30, "123-45-6789");
console.log(person.name);   // "Alice"
// console.log(person.ssn);  // Error: private
```

## アクセス修飾子

### public（デフォルト）

```typescript
class Animal {
    public name: string = "Anonymous";

    public move(): void {
        console.log("Moving...");
    }
}

const animal: Animal = new Animal();
console.log(animal.name);  // アクセス可
animal.move();             // アクセス可
```

### private

```typescript
class BankAccount {
    public accountNumber: string;
    private balance: number;

    constructor(accountNumber: string, initialBalance: number) {
        this.accountNumber = accountNumber;
        this.balance = initialBalance;
    }

    public deposit(amount: number): void {
        this.balance += amount;
    }

    public getBalance(): number {
        return this.balance;
    }

    // private メソッド
    private logTransaction(amount: number): void {
        console.log(`Transaction: ${amount}`);
    }
}

const account: BankAccount = new BankAccount("12345", 1000);
console.log(account.getBalance());  // 1000
// console.log(account.balance);    // Error: private
```

### protected

```typescript
class Vehicle {
    protected speed: number = 0;

    protected accelerate(amount: number): void {
        this.speed += amount;
    }
}

class Car extends Vehicle {
    accelerateMore(): void {
        this.accelerate(20);  // protectedメンバーにアクセス可
        console.log(`Speed: ${this.speed}`);
    }
}

const car: Car = new Car();
car.accelerateMore();  // "Speed: 20"
// car.speed = 50;    // Error: protectedはクラス外からアクセス不可
```

### readonly

```typescript
class Config {
    readonly apiUrl: string;
    readonly timeout: number;

    constructor(apiUrl: string, timeout: number) {
        this.apiUrl = apiUrl;
        this.timeout = timeout;
    }
}

const config: Config = new Config("https://api.example.com", 5000);
console.log(config.apiUrl);  // アクセス可
// config.apiUrl = "new-url";  // Error: readonly
```

## 継承

```typescript
class Animal {
    name: string;

    constructor(name: string) {
        this.name = name;
    }

    move(): void {
        console.log(`${this.name} is moving`);
    }
}

class Dog extends Animal {
    breed: string;

    constructor(name: string, breed: string) {
        super(name);  // 親クラスのコンストラクタを呼び出す
        this.breed = breed;
    }

    move(): void {
        console.log(`${this.name} (${this.breed}) is running`);
    }

    bark(): void {
        console.log(`${this.name} says Woof!`);
    }
}

const dog: Dog = new Dog("Max", "Golden Retriever");
dog.move();   // "Max (Golden Retriever) is running"
dog.bark();   // "Max says Woof!"
```

## 抽象クラス

```typescript
abstract class Shape {
    abstract getArea(): number;

    describe(): string {
        return `Area: ${this.getArea()}`;
    }
}

class Circle extends Shape {
    constructor(private radius: number) {
        super();
    }

    getArea(): number {
        return Math.PI * this.radius * this.radius;
    }
}

class Rectangle extends Shape {
    constructor(private width: number, private height: number) {
        super();
    }

    getArea(): number {
        return this.width * this.height;
    }
}

const circle: Circle = new Circle(5);
const rect: Rectangle = new Rectangle(4, 6);

console.log(circle.describe());  // "Area: 78.53981633974483"
console.log(rect.describe());    // "Area: 24"

// const shape: Shape = new Shape();  // Error: abstract
```

## インターフェース

### 基本形

```typescript
interface Animal {
    name: string;
    age: number;
    move(): void;
}

class Dog implements Animal {
    name: string;
    age: number;

    constructor(name: string, age: number) {
        this.name = name;
        this.age = age;
    }

    move(): void {
        console.log(`${this.name} is moving`);
    }
}

const dog: Dog = new Dog("Buddy", 3);
const animal: Animal = dog;  // インターフェース型で参照可
```

### 複数のインターフェース実装

```typescript
interface Drawable {
    draw(): void;
}

interface Resizable {
    resize(width: number, height: number): void;
}

class Shape implements Drawable, Resizable {
    private width: number = 100;
    private height: number = 100;

    draw(): void {
        console.log(`Drawing ${this.width}x${this.height}`);
    }

    resize(width: number, height: number): void {
        this.width = width;
        this.height = height;
    }
}

const shape: Shape = new Shape();
shape.resize(200, 150);
shape.draw();  // "Drawing 200x150"
```

### インターフェースの継承

```typescript
interface Vehicle {
    speed: number;
}

interface Car extends Vehicle {
    wheels: number;
}

class Tesla implements Car {
    speed: number = 200;
    wheels: number = 4;
}

const tesla: Tesla = new Tesla();
console.log(tesla.speed, tesla.wheels);  // 200 4
```

## インターフェース vs 型エイリアス

```typescript
// インターフェース
interface Point {
    x: number;
    y: number;
}

// 型エイリアス
type PointType = {
    x: number;
    y: number;
};

// マージ（インターフェースのみ）
interface Point {
    z?: number;  // インターフェースは自動的にマージされる
}

// extends（両方対応）
interface Point3D extends Point {
    z: number;
}

type PointType3D = PointType & { z: number };
```

## ジェネリクス

```typescript
interface Repository<T> {
    getById(id: number): T;
    save(item: T): void;
}

class UserRepository implements Repository<User> {
    private users: User[] = [];

    getById(id: number): User | undefined {
        return this.users.find(u => u.id === id);
    }

    save(user: User): void {
        this.users.push(user);
    }
}

interface User {
    id: number;
    name: string;
}

const repo: UserRepository = new UserRepository();
repo.save({ id: 1, name: "Alice" });
```

## スタティックメンバ

```typescript
class MathUtils {
    static PI: number = 3.14159;

    static circleArea(radius: number): number {
        return this.PI * radius * radius;
    }
}

console.log(MathUtils.PI);              // 3.14159
console.log(MathUtils.circleArea(5));   // 78.53975
```

## 📌 重要なポイント

- **クラス**: オブジェクト指向プログラミングの基本
- **アクセス修飾子**: `public`, `private`, `protected`, `readonly`
- **継承**: `extends`で親クラスの機能を引き継ぐ
- **抽象クラス**: 子クラスで実装を強制
- **インターフェース**: 型の契約を定義
- **ジェネリクス**: 汎用的な型を実現
