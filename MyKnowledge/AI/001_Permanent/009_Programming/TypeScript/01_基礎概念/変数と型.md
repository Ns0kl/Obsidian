# 変数と型

## 概要

**TypeScript**は、JavaScriptに静的型付けを加えたプログラミング言語です。コンパイル時に型をチェックしてバグを防ぎます。

## 変数の宣言

### let・const・var

```typescript
// let: ブロックスコープの変数（再代入可能）
let x: number = 5;
x = 10;  // OK

// const: ブロックスコープの定数（再代入不可）
const y: number = 10;
// y = 20;  // Error: 再代入できない

// var: 関数スコープの変数（非推奨）
var z: number = 15;
```

### 型アノテーション

```typescript
// 明示的に型を指定
let name: string = "Alice";
let age: number = 30;
let isActive: boolean = true;

// 型推論：型を指定しないと自動判定
let message = "Hello";  // stringと推論
let count = 42;         // numberと推論
```

## 基本的なデータ型

### プリミティブ型

```typescript
// 文字列
let text: string = "hello";
let template: string = `Hello, ${name}!`;

// 数値（整数・小数両方）
let integer: number = 42;
let decimal: number = 3.14;
let hex: number = 0xFF;
let binary: number = 0b1010;

// 論理値
let isTrue: boolean = true;
let isFalse: boolean = false;

// undefined・null
let undef: undefined = undefined;
let empty: null = null;
```

### 特殊な型

```typescript
// any型：任意の型（型チェックなし）
let anyValue: any = "string";
anyValue = 123;  // OK（推奨されない）

// unknown型：安全なany型
let unknownValue: unknown = "string";
// unknownValue.toUpperCase();  // Error: チェックが必要

// never型：値を持たない型
function throwError(): never {
    throw new Error("This never returns");
}
```

## 型変換

### 明示的な型変換

```typescript
// 文字列への変換
const num: number = 42;
const str1: string = String(num);          // "42"
const str2: string = num.toString();       // "42"
const str3: string = `${num}`;             // "42"

// 数値への変換
const strNum: string = "123";
const num1: number = Number(strNum);       // 123
const num2: number = parseInt(strNum);     // 123
const num3: number = parseFloat("3.14");   // 3.14

// 論理値への変換
const bool: boolean = Boolean(1);          // true
const bool2: boolean = !!0;                // false
```

## Union型とLiteral型

### Union型（複数の型の組み合わせ）

```typescript
// 複数の型を許可
let value: string | number;
value = "hello";  // OK
value = 42;       // OK
// value = true;  // Error

// 複数の型から選択
function process(input: string | number): void {
    if (typeof input === 'string') {
        console.log(input.toUpperCase());
    } else {
        console.log(input * 2);
    }
}
```

### Literal型（特定の値のみ許可）

```typescript
// 特定の値のみ許可
let direction: "north" | "south" | "east" | "west";
direction = "north";   // OK
// direction = "up";   // Error

// 数値のLiteral型
let status: 200 | 404 | 500;
status = 200;  // OK
// status = 201;  // Error
```

## 型エイリアス

```typescript
// 型を定義・再利用
type ID = string | number;
type Status = "active" | "inactive" | "pending";

let userId: ID = "user-123";  // OK
let userStatus: Status = "active";  // OK

// 関数型
type Callback = (data: string) => void;
const myCallback: Callback = (data) => {
    console.log(data);
};
```

## any 型を避ける

```typescript
// 悪い例
let value: any = "123";
value.toUpperCase();  // 型チェックなし
value.toDateString();  //実行時エラー

// 良い例：型安全
let value: string = "123";
value.toUpperCase();  // OK
// value.toDateString();  // Compile error

// unknown を使う場合
let unknown: unknown = "123";
if (typeof unknown === 'string') {
    unknown.toUpperCase();  // OK
}
```

## 📌 重要なポイント

- **型アノテーション**: 変数に型を指定して安全性を確保
- **型推論**: 型を指定しないと自動判定される
- **let vs const**: constを優先的に使う
- **Union型**: `|`で複数の型を許可
- **Literal型**: 特定の値のみを許可する
- **any型を避ける**: unknownやより具体的な型を使用
