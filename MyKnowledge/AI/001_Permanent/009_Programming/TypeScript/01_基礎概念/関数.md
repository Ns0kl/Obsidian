# 関数

## 概要

**関数**は、再利用可能なコードのブロックです。TypeScriptでは、パラメータと戻り値に型を指定します。

## 関数の定義と呼び出し

### 基本形

```typescript
// 関数定義
function greet(): void {
    console.log("Hello!");
}

// 関数呼び出し
greet();  // Hello!
```

### パラメータと戻り値

```typescript
function add(a: number, b: number): number {
    return a + b;
}

const result: number = add(3, 5);
console.log(result);  // 8
```

### 複数の戻り値

```typescript
// タプル型で複数の値を返す
function divmod(a: number, b: number): [number, number] {
    const quotient: number = Math.floor(a / b);
    const remainder: number = a % b;
    return [quotient, remainder];
}

const [q, r] = divmod(17, 5);
console.log(q, r);  // 3 2
```

## 関数の型

### 関数型

```typescript
// 関数型の定義
type Callback = (data: string) => void;

const myCallback: Callback = (data: string) => {
    console.log(data);
};

myCallback("Hello");  // Hello
```

### 関数オーバーロード

```typescript
// 同じ名前で異なるシグネチャを定義
function process(input: string): string;
function process(input: number): number;
function process(input: string | number): string | number {
    if (typeof input === 'string') {
        return input.toUpperCase();
    } else {
        return input * 2;
    }
}

console.log(process("hello"));  // "HELLO"
console.log(process(5));        // 10
```

## アロー関数

```typescript
// 基本形
const add = (a: number, b: number): number => {
    return a + b;
};

// 式が1行の場合はreturnを省略
const multiply = (a: number, b: number): number => a * b;

// パラメータが1つの場合は括弧を省略可
const square = (x: number): number => x * x;

// パラメータなし
const random = (): number => Math.random();

console.log(add(3, 5));        // 8
console.log(multiply(3, 5));   // 15
console.log(square(5));        // 25
```

## デフォルト値

```typescript
function greet(name: string = "Guest"): string {
    return `Hello, ${name}!`;
}

console.log(greet());           // "Hello, Guest!"
console.log(greet("Alice"));    // "Hello, Alice!"
```

## オプショナルパラメータ

```typescript
function printInfo(name: string, age?: number): void {
    if (age !== undefined) {
        console.log(`${name} is ${age} years old`);
    } else {
        console.log(`Name: ${name}`);
    }
}

printInfo("Alice", 30);  // "Alice is 30 years old"
printInfo("Bob");        // "Name: Bob"
```

## レストパラメータ

```typescript
// 可変長パラメータ
function sum(...numbers: number[]): number {
    return numbers.reduce((acc, num) => acc + num, 0);
}

console.log(sum(1, 2, 3));      // 6
console.log(sum(1, 2, 3, 4, 5));  // 15

// 複数の型
function combine(first: string, ...rest: string[]): string {
    return [first, ...rest].join(", ");
}

console.log(combine("A", "B", "C"));  // "A, B, C"
```

## クロージャ

```typescript
function createCounter(): () => number {
    let count: number = 0;
    
    return function(): number {
        count++;
        return count;
    };
}

const counter = createCounter();
console.log(counter());  // 1
console.log(counter());  // 2
console.log(counter());  // 3
```

## 高階関数

### 関数を引数に受け取る

```typescript
function apply(fn: (x: number) => number, value: number): number {
    return fn(value);
}

const double = (x: number): number => x * 2;
const square = (x: number): number => x * x;

console.log(apply(double, 5));   // 10
console.log(apply(square, 5));   // 25
```

### 関数を戻す

```typescript
function createMultiplier(factor: number): (x: number) => number {
    return (x: number): number => x * factor;
}

const double = createMultiplier(2);
const triple = createMultiplier(3);

console.log(double(5));   // 10
console.log(triple(5));   // 15
```

## コールバック関数

```typescript
function fetchData(callback: (error: Error | null, data?: string) => void): void {
    setTimeout(() => {
        const success = Math.random() > 0.5;
        if (success) {
            callback(null, "Data loaded");
        } else {
            callback(new Error("Failed to load"));
        }
    }, 1000);
}

fetchData((error, data) => {
    if (error) {
        console.log("Error:", error.message);
    } else {
        console.log("Success:", data);
    }
});
```

## 関数のベストプラクティス

### 型注釈の活用

```typescript
// 良い例：型安全
function processUser(user: { id: number; name: string }): string {
    return `User: ${user.name}`;
}

// インターフェースを使うとさらに良い
interface User {
    id: number;
    name: string;
}

function processUserBetter(user: User): string {
    return `User: ${user.name}`;
}
```

### 例外処理

```typescript
function divide(a: number, b: number): number {
    if (b === 0) {
        throw new Error("Division by zero");
    }
    return a / b;
}

try {
    const result = divide(10, 0);
} catch (error) {
    console.error("Error:", error);
}
```

## 📌 重要なポイント

- **型注釈**: パラメータと戻り値の型を指定
- **void**: 戻り値がない場合
- **アロー関数**: 簡潔な記述が可能
- **デフォルト値**: パラメータのデフォルト値を設定
- **オプショナル**: `?`でパラメータを省略可能に
- **レストパラメータ**: `...`で可変長引数
