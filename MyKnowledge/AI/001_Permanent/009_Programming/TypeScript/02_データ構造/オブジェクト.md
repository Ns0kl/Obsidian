# オブジェクト

## 概要

**オブジェクト**は、キーと値のペアでデータを管理するデータ構造です。JavaScriptの中心的な概念です。

## オブジェクトの基本

### オブジェクトリテラル

```typescript
// 基本形
const person: { name: string; age: number } = {
    name: "Alice",
    age: 30
};

console.log(person.name);   // "Alice"
console.log(person.age);    // 30
console.log(person["name"]); // "Alice"
```

### 型定義

```typescript
// インターフェース
interface User {
    id: number;
    name: string;
    email: string;
    age?: number;  // オプショナル
}

const user: User = {
    id: 1,
    name: "Alice",
    email: "alice@example.com"
};

// 型エイリアス
type Person = {
    firstName: string;
    lastName: string;
    age: number;
};

const person: Person = {
    firstName: "Bob",
    lastName: "Smith",
    age: 25
};
```

## プロパティアクセス

```typescript
const obj: { [key: string]: any } = {
    name: "Alice",
    age: 30,
    city: "Tokyo"
};

// ドット記法
console.log(obj.name);         // "Alice"

// ブラケット記法
console.log(obj["age"]);       // 30

// 動的アクセス
const key: string = "city";
console.log(obj[key]);         // "Tokyo"

// プロパティの追加
obj.country = "Japan";
obj["hobby"] = "Reading";
```

## デストラクチャリング

```typescript
// オブジェクトの分割代入
const person: { name: string; age: number; city: string } = {
    name: "Alice",
    age: 30,
    city: "Tokyo"
};

const { name, age } = person;
console.log(name, age);  // "Alice" 30

// 別の名前で割り当て
const { name: userName, age: userAge } = person;
console.log(userName, userAge);  // "Alice" 30

// デフォルト値
const { name: n = "Unknown", country = "Japan" } = person;
console.log(n, country);  // "Alice" "Japan"

// ネストされたデストラクチャリング
const profile: { user: { name: string; id: number }; bio: string } = {
    user: { name: "Bob", id: 1 },
    bio: "Developer"
};

const { user: { name: userName2 } } = profile;
console.log(userName2);  // "Bob"
```

## スプレッド演算子

```typescript
const obj1: { a: number; b: number } = { a: 1, b: 2 };
const obj2: { c: number } = { c: 3 };

// オブジェクトの合成
const merged: { a: number; b: number; c: number } = { ...obj1, ...obj2 };
console.log(merged);  // { a: 1, b: 2, c: 3 }

// プロパティの上書き
const updated: { a: number; b: number } = { ...obj1, a: 10 };
console.log(updated);  // { a: 10, b: 2 }

// コピー
const copy: { a: number; b: number } = { ...obj1 };
copy.a = 100;
console.log(obj1.a);  // 1（元は変わらない）
```

## メソッド

```typescript
interface Calculator {
    value: number;
    add(n: number): void;
    subtract(n: number): void;
    getValue(): number;
}

const calc: Calculator = {
    value: 0,
    add(n: number): void {
        this.value += n;
    },
    subtract(n: number): void {
        this.value -= n;
    },
    getValue(): number {
        return this.value;
    }
};

calc.add(5);
calc.add(3);
console.log(calc.getValue());  // 8
```

## this の扱い

```typescript
const person: { name: string; greet(this: { name: string }): void } = {
    name: "Alice",
    greet() {
        console.log(`Hello, I'm ${this.name}`);
    }
};

person.greet();  // "Hello, I'm Alice"

// アロー関数ではthisが外側のコンテキストを継承
const obj: { name: string; method: () => void } = {
    name: "Bob",
    method: () => {
        console.log(this);  // 外側のthis
    }
};
```

## オブジェクトの反復処理

```typescript
const person: { name: string; age: number; city: string } = {
    name: "Alice",
    age: 30,
    city: "Tokyo"
};

// キーの列挙
for (const key in person) {
    console.log(key, person[key as keyof typeof person]);
}

// Object.keys
const keys: string[] = Object.keys(person);
console.log(keys);  // ["name", "age", "city"]

// Object.values
const values: any[] = Object.values(person);
console.log(values);  // ["Alice", 30, "Tokyo"]

// Object.entries
const entries: [string, any][] = Object.entries(person);
entries.forEach(([key, value]) => {
    console.log(`${key}: ${value}`);
});
```

## 読み取り専用プロパティ

```typescript
interface Config {
    readonly apiUrl: string;
    readonly timeout: number;
    retryCount: number;
}

const config: Config = {
    apiUrl: "https://api.example.com",
    timeout: 5000,
    retryCount: 3
};

// config.apiUrl = "new-url";  // Error: readonly
config.retryCount = 5;  // OK
```

## オプショナルプロパティと必須プロパティ

```typescript
interface User {
    name: string;           // 必須
    email?: string;         // オプショナル
    phone?: string;         // オプショナル
}

const user1: User = { name: "Alice" };
const user2: User = { name: "Bob", email: "bob@example.com" };

// Partial型：すべてのプロパティをオプショナルに
type PartialUser = Partial<User>;
const update: PartialUser = { name: "Charlie" };

// Required型：すべてのプロパティを必須に
type RequiredUser = Required<User>;
```

## Mapped Types

```typescript
// 各プロパティをboolean型にマッピング
type Getters<T> = {
    [K in keyof T]: () => T[K];
};

interface Person {
    name: string;
    age: number;
}

type PersonGetters = Getters<Person>;
// { name: () => string; age: () => number; }

// すべてのプロパティを読み取り専用に
type Readonly<T> = {
    readonly [K in keyof T]: T[K];
};
```

## 📌 重要なポイント

- **インターフェース**: オブジェクトの型を定義
- **デストラクチャリング**: プロパティを変数に展開
- **スプレッド演算子**: オブジェクトの合成とコピー
- **readonly**: 読み取り専用プロパティ
- **Partial・Required**: プロパティの必須性を変更
- **Mapped Types**: プロパティを一括変換
