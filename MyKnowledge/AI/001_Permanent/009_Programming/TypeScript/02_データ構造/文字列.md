# 文字列

## 概要

**文字列**は、文字のシーケンスです。TypeScriptではテンプレートリテラルや豊富なメソッドが利用できます。

## 文字列の基本

### 文字列リテラル

```typescript
// シングルクォート
const str1: string = 'Hello';

// ダブルクォート
const str2: string = "World";

// バックティック（テンプレートリテラル）
const str3: string = `Hello World`;

// 長さ
console.log(str1.length);  // 5
```

### エスケープシーケンス

```typescript
const path: string = 'C:\\Users\\username';
console.log(path);  // C:\Users\username

const quote: string = "He said \"Hello\"";
console.log(quote);  // He said "Hello"

const newline: string = 'Line1\\nLine2';
const tab: string = 'Col1\\tCol2';
```

## テンプレートリテラル

```typescript
const name: string = "Alice";
const age: number = 30;
const city: string = "Tokyo";

// 変数の埋め込み
const message: string = `${name} is ${age} years old from ${city}`;
console.log(message);  // "Alice is 30 years old from Tokyo"

// 式の埋め込み
const result: string = `The answer is ${10 + 20}`;
console.log(result);  // "The answer is 30"

// 関数呼び出し
function getTitle(): string {
    return "Mr.";
}
const formal: string = `${getTitle()} ${name}`;
console.log(formal);  // "Mr. Alice"

// 複数行
const multiLine: string = `
    First line
    Second line
    Third line
`;
```

## インデックスとスライス

```typescript
const str: string = "Hello";

// インデックスアクセス
console.log(str[0]);      // "H"
console.log(str[4]);      // "o"
console.log(str[10]);     // undefined

// charAt
console.log(str.charAt(0));      // "H"
console.log(str.charAt(10));     // ""

// charCodeAt
console.log(str.charCodeAt(0));  // 72 (Hのコード)
```

## 文字列操作メソッド

### 大文字・小文字

```typescript
const str: string = "Hello World";

console.log(str.toUpperCase());    // "HELLO WORLD"
console.log(str.toLowerCase());    // "hello world"
```

### 検索

```typescript
const str: string = "https://www.example.com/path/to/page";

// indexOfで位置を取得
const idx: number = str.indexOf("/");
console.log(idx);      // 6
console.log(str.substring(0, idx));  // "https:"

// 見つからない場合
console.log(str.indexOf("xyz"));  // -1

// 最後に現れる位置
console.log(str.lastIndexOf("/"));  // 30

// 文字列を含むか
console.log(str.includes("example"));  // true
console.log(str.includes("test"));     // false

// 開始・終了チェック
console.log(str.startsWith("https"));  // true
console.log(str.endsWith("page"));     // true
```

### スライス・サブストリング

```typescript
const str: string = "Hello World";

// slice
console.log(str.slice(0, 5));    // "Hello"
console.log(str.slice(6));       // "World"
console.log(str.slice(-5));      // "World"

// substring
console.log(str.substring(0, 5));  // "Hello"
console.log(str.substring(6));     // "World"

// substr（非推奨）
console.log(str.substr(0, 5));     // "Hello"
```

### 置換

```typescript
const str: string = "The quick brown fox jumps over the lazy dog";

// replace：最初の1つだけ置換
const replaced1: string = str.replace("quick", "slow");
console.log(replaced1);  // "The slow brown fox..."

// replaceAll：すべて置換
const replaced2: string = str.replaceAll("o", "0");
console.log(replaced2);  // "The quick brwn f0x jumps 0ver the lazy d0g"

// 正規表現を使用
const replaced3: string = str.replace(/o/g, "0");
console.log(replaced3);  // replaceAllと同じ
```

### 分割・連結

```typescript
const csv: string = "apple,banana,orange";

// split
const fruits: string[] = csv.split(",");
console.log(fruits);  // ["apple", "banana", "orange"]

// join
const joined: string = fruits.join(" - ");
console.log(joined);  // "apple - banana - orange"

// 限界を指定
const limited: string[] = csv.split(",", 2);
console.log(limited);  // ["apple", "banana"]
```

### トリミング

```typescript
const str: string = "  hello world  ";

console.log(str.trim());       // "hello world"
console.log(str.trimStart());  // "hello world  "
console.log(str.trimEnd());    // "  hello world"
```

### パディング

```typescript
const str: string = "42";

console.log(str.padStart(5, "0"));  // "00042"
console.log(str.padEnd(5, "0"));    // "42000"
```

### リピート

```typescript
const str: string = "ab";

console.log(str.repeat(3));  // "ababab"
console.log("-".repeat(10)); // "----------"
```

## 文字列の条件確認

```typescript
const str: string = "Hello123";

// 等式
console.log(str === "Hello123");   // true
console.log(str === "hello123");   // false（大文字小文字区別）

// 比較（辞書順）
console.log("apple" < "banana");   // true
console.log("123" < "456");        // true
```

## 正規表現

```typescript
// 正規表現の作成
const emailRegex: RegExp = /^[^\\s@]+@[^\\s@]+\\.[^\\s@]+$/;
const numberRegex: RegExp = /^\\d+$/;

// テスト
console.log(emailRegex.test("alice@example.com"));  // true
console.log(emailRegex.test("invalid-email"));      // false

console.log(numberRegex.test("12345"));             // true
console.log(numberRegex.test("123abc"));            // false

// マッチング
const text: string = "The price is $100 and $200";
const prices: RegExpMatchArray | null = text.match(/\\$(\\d+)/g);
console.log(prices);  // ["$100", "$200"]

// 置換
const replaced: string = text.replace(/\\$(\\d+)/g, "¥$1");
console.log(replaced);  // "The price is ¥100 and ¥200"
```

## テンプレートタグ関数

```typescript
// タグ関数の定義
function highlight(
    strings: TemplateStringsArray,
    ...values: any[]
): string {
    return strings
        .map((str, i) => str + (values[i] ? `**${values[i]}**` : ""))
        .join("");
}

// 使用
const name: string = "Alice";
const age: number = 30;
const result: string = highlight`My name is ${name} and I'm ${age} years old`;
console.log(result);  // "My name is **Alice** and I'm **30** years old"
```

## 📌 重要なポイント

- **テンプレートリテラル**: `${}`で変数を埋め込める
- **split/join**: 文字列の分割と連結
- **indexOf/includes**: 文字列の検索
- **slice**: 部分文字列の抽出
- **replace/replaceAll**: 文字列の置換
- **正規表現**: 複雑なパターンマッチングに便利
