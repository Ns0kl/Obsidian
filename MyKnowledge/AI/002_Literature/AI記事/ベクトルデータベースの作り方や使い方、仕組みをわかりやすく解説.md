### 0\. ベクトル埋め込み

まずは、ベクトル埋め込みを利用して [データ](#) をベクトルに変換する必要があります。  
※ [OpenSearch](https://hogetech.info/bigdata/elasticsearch "【入門】Elasticsearchとは？用途や使い方をわかりやすく解説") 外の作業

| 変換前のデータ | ベクトル埋め込み |
| --- | --- |
| 単語 | Word2Vec, GloVe, FastText |
| 文章 | Universal Sentence Encoder (USE) |
| ドキュメント | Doc2Vec |
| 画像 | [CNN](https://hogetech.info/machine-learning/deep-learning/dl-basic5 "CNN") |
| 地理空間 | 国土地理院 API |

### 1\. k-NN インデックスを作成

![](https://hogetech.info/wp-content/uploads/2024/08/7fb8f1c748d490339c64aa37f2515920-4.png)

k=3 の場合、最も近い 3 要素を検索

何をもって"近い"とするかは、 [OpenSearch](https://hogetech.info/bigdata/elasticsearch "【入門】Elasticsearchとは？用途や使い方をわかりやすく解説") の space\_type で設定できます。([こちら](https://opensearch.org/docs/latest/search-plugins/knn/knn-score-script/#spaces))

![](https://hogetech.info/wp-content/uploads/2024/08/01e20b05948409296d32314122ce234d-6.png)

絶対値に強く影響を受け、C の方が近くなります 緯度、経度を例にすると、地理的距離が近い方が近くなります

![](https://hogetech.info/wp-content/uploads/2024/08/deb17bd5bd307fcd49379fd7617489d9-6.png)

カテゴリで分ける傾向にあり、B の方が近くなります 緯度、経度を例にすると、方角が近い方が近くなります。

```rust
PUT prefectures
{
  "settings": {
    "index.knn":true
  },
  "mappings": {
    "properties": {
      "location": {
        "type": "knn_vector",
        "dimension": 2
      }
    }
  }
}
```

## OpenSearch 内でベクトルを生成

![](https://hogetech.info/wp-content/uploads/2024/08/01e20b05948409296d32314122ce234d-3.png)

![](https://hogetech.info/wp-content/uploads/2024/08/deb17bd5bd307fcd49379fd7617489d9-1.png)

[OpenSearch](https://hogetech.info/bigdata/elasticsearch "【入門】Elasticsearchとは？用途や使い方をわかりやすく解説") では、Neural search を利用すると、クエリに含まれる [データ](#) をベクトルに変換してから保存・検索できます。

![](https://hogetech.info/wp-content/uploads/2024/08/1802783db20269aba22a3ea93b92cabe-1.png)

ニューラル検索で利用できるベクトル変換モデル (ML モデル) は以下のとおりです。

| 検索方法 | 用途 | ベクトル変換モデル (ML モデル) |
| --- | --- | --- |
| [セマンティック検索](https://opensearch.org/docs/latest/search-plugins/semantic-search/) | テキストの意味を考慮して検索 | テキスト埋め込みモデル |
| [マルチモーダル検索](https://opensearch.org/docs/latest/search-plugins/multimodal-search/) | 画像検索 | マルチモーダル埋め込みモデル |
| [スパース検索](https://opensearch.org/docs/latest/search-plugins/neural-sparse-search/) | スパース検索   (計算コストの削減) | スパース埋め込みモデル |
| [会話型検索](https://opensearch.org/docs/latest/search-plugins/conversational-search/) | 自然言語で会話するように検索 | [大規模言語モデル](https://hogetech.info/ml/rag#llm "llm") ([LLM](https://hogetech.info/ml/rag#llm "llm")) |

今回は [MS MARCO](https://microsoft.github.io/msmarco/) モデルを利用して、 [セマンティック検索](https://hogetech.info/database/elasticsearch#semantic "セマンティック検索") を行います。

### 1\. ML モデルをセットアップ

前提条件： [メモリ](https://hogetech.info/linux/kernel/memory#memory "メモリ") の潤沢なマシンを使ってください。

```yaml
PUT _cluster/settings
{
  "persistent": {
    "plugins.ml_commons.only_run_on_ml_node": false
  }
}
```

msmarco-distilbert-base-tas-b という [MS MARCO](https://microsoft.github.io/msmarco/) モデルを登録します。

```
POST /_plugins/_ml/models/_register
{
  "name": "huggingface/sentence-transformers/msmarco-distilbert-base-tas-b",
  "version": "1.0.1",
  "model_format": "TORCH_SCRIPT"
}
```

```
GET /_plugins/_ml/tasks/_search
{}
```

```python
"state": "COMPLETED",
"model_id": "0123456789abcdefghij",
```

※state が CREATED から COMPLETED になると、model\_id が表示されます。

```
POST /_plugins/_ml/models/model_id/_deploy
```

デプロイが完了したかどうかは、GET /\_plugins/\_ml/tasks/\_search で確認できます。

### 2\. Neural search でデータ取込

```python
PUT /_ingest/pipeline/nlp-ingest-pipeline
{
  "processors": [
    {
      "text_embedding": {
        "model_id": "model_id",
        "field_map": {
          "text": "passage_embedding"
        }
      }
    }
  ]
}
```

[OpenSearch](https://hogetech.info/bigdata/elasticsearch "【入門】Elasticsearchとは？用途や使い方をわかりやすく解説") 外でベクトルを生成する場合と同じく、 [k-NN](https://hogetech.info/ml/algorithm/knn "【入門】k-NN (k近傍法) とは？わかりやすく解説") [インデックス](https://hogetech.info/database/design/index "[データベース]インデックスの意味やメリットとデメリットを解説") を作成します。

```perl
PUT /my-nlp-index
{
  "settings": {
    "index.knn": true,
    "default_pipeline": "nlp-ingest-pipeline"
  },
  "mappings": {
    "properties": {
      "passage_embedding": {
        "type": "knn_vector",
        "dimension": 768
      },
      "text": {
        "type": "text"
      }
    }
  }
}
```

dimension は [モデルの次元に合わせて 768](https://opensearch.org/docs/latest/ml-commons-plugin/pretrained-models/#sentence-transformers) にします。

```python
POST _bulk
{ "index": { "_index": "my-nlp-index", "_id": "東京" } }
{ "text": "Tokyo is the capital of Japan and one of the most populous cities in the world, with a population of over 14 million residents as of 2023 and the second-most-populated capital in the world." }
{ "index": { "_index": "my-nlp-index", "_id": "北海道" } }
{ "text": "Hokkaido is the second-largest island of Japan and comprises the largest and northernmost prefecture, making up its own region." }
{ "index": { "_index": "my-nlp-index", "_id": "沖縄" } }
{ "text": "Okinawa Prefecture is the southernmost and westernmost prefecture of Japan." }
{ "index": { "_index": "my-nlp-index", "_id": "大阪" } }
{ "text": "Osaka is a designated city in the Kansai region of Honshu in Japan, and one of the three major cities of Japan (Tokyo-Osaka-Nagoya)." }
```
