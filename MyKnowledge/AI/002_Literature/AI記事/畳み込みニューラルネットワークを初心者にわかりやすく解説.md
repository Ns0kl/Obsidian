## 従来のニューラルネットワークと CNN の違い

## 畳み込み層 (Convolution) とは

畳み込み層では、以下の処理を行います。

- 畳み込み演算（画像処理で言う「フィルタ演算にあたる」）
	- バイアスの演算
- パディング
- ストライド
- フィルターを追加
- 次元を追加

### 畳み込み演算とは

畳み込み演算は以下のような演算です。フィルタが重み W に相当します。

![](https://hogetech.info/wp-content/uploads/2022/03/1d2490d6be293d397574ecc5b66eb1ff-2.png)

⊛ は積和演算

畳み込み演算では、以下のようにフィルタと対応する要素を乗算し、その和を求めます。（積和演算）

![](https://hogetech.info/wp-content/uploads/2022/03/beaffbfc9d6177df55fc56812c7dacb6.png)

![](https://hogetech.info/wp-content/uploads/2022/03/926669e5f1011dca3bf240111ec8c923.png)

![](https://hogetech.info/wp-content/uploads/2022/03/1b026e84d361a6428de218cfb1471068.png)

![](https://hogetech.info/wp-content/uploads/2022/03/920e2f110ee98b9de1a0a4c1fa325ac0.png)

#### バイアスの演算

[畳み込みニューラルネットワーク](https://hogetech.info/machine-learning/deep-learning/dl-basic5 "CNN") では、以下のようにバイアス B を演算します。

![](https://hogetech.info/wp-content/uploads/2022/03/ddf450575bf64ebf5512cb0284482475-2.png)

畳み込み演算を行うと、出力のサイズがどんどん小さくなってしまい、最後は畳み込み演算ができなくなってしまいます。

![](https://hogetech.info/wp-content/uploads/2022/03/e83764835640335b8b7d19ea8b5a17a8.png)

そこで、入力の周囲を０で埋めることで、出力のサイズを調整します。

![](https://hogetech.info/wp-content/uploads/2022/03/8da89575c9b3441c9971d7a8cbab1c3e-8.png)

![](https://hogetech.info/wp-content/uploads/2022/03/df292ad6b3fa1d41cf98b96a04be1b8e-5.png)

スライドが大きくなると、出力は小さくなります。

- スライド：１ → 出力 (３，３)
- スライド：２ → 出力 (２，２)

### フィルターを追加

![](https://hogetech.info/wp-content/uploads/2022/03/479089b78010423b5702baaaa414bf52-4.png)

１入力に対して、３つのフィルターでそれぞれ畳み込み演算を行い、３つの出力を得ます。

> 通常、画像はさまざまな直線・曲線などが組み合わさって構成されるので、1つのフィルタを用いて判別するよりも、複数のフィルタを組み合わせて判別したほうが、識別性能が上がりやすい。

### 次元を追加 (カラーの画像認識)

画像の「縦」と「横」の２次元から、「色 (チャンネル)」を追加した３次元を例に見ていきます。

今回、色の表現方法はRGB（Red, Green, Blue）を利用します。

![](https://hogetech.info/wp-content/uploads/2022/03/40e3078c472ee171d679268e4eda7e8b-2.png)

オレンジ(FFC000) は、Red = 255, Green =192, Blue =0 です 「１入力、１フィルター (１枚のオレンジの７)」 です。「色 (チャンネル) = Z 軸方向」に要素を分解してるだけです

入力 X とフィルタ W の要素ごとに畳み込み演算を行い、３つの演算結果 (赤・緑・青) を合計したものが出力となります。  
(元々１枚の画像を３つの RGB に分けて計算しただけなので、最後は合計して１枚に戻します。)

### 畳み込み演算を Python で実装

![](https://hogetech.info/wp-content/uploads/2022/03/8da89575c9b3441c9971d7a8cbab1c3e-7.png)

上記の畳み込み演算を実装した結果が以下のとおりです。(im2col の実装は [こちら](https://github.com/oreilly-japan/deep-learning-from-scratch/blob/master/common/util.py))

```
def im2col(input_data, filter_h, filter_w, stride=1, pad=0):
    """

    Parameters
    ----------
    input_data : (データ数, チャンネル, 高さ, 幅)の4次元配列からなる入力データ
    filter_h : フィルターの高さ
    filter_w : フィルターの幅
    stride : ストライド
    pad : パディング

    Returns
    -------
    col : 2次元配列
    """
    N, C, H, W = input_data.shape
    out_h = (H + 2*pad - filter_h)//stride + 1
    out_w = (W + 2*pad - filter_w)//stride + 1

    img = np.pad(input_data, [(0,0), (0,0), (pad, pad), (pad, pad)], 'constant')
    col = np.zeros((N, C, filter_h, filter_w, out_h, out_w))

    for y in range(filter_h):
        y_max = y + stride*out_h
        for x in range(filter_w):
            x_max = x + stride*out_w
            col[:, :, y, x, :, :] = img[:, :, y:y_max:stride, x:x_max:stride]

    col = col.transpose(0, 4, 5, 1, 2, 3).reshape(N*out_h*out_w, -1)
    return col

input = np.array([[[[0,1,2,3],[1,2,3,0],[2,3,0,1],[3,0,1,2]]]]) #入力 X
filter = np.array([[0,1,2],[1,2,0],[2,0,1]]) #フィルタ W

input_col = im2col(input,3,3,1,1) #引数の詳細はim2col 参照
filter_col = filter.reshape(1, -1).T 
output = np.dot(input_col,filter_col) #出力 Z
print(output.reshape(4,4)) #出力Z の形
```

## プーリング層 (Pooling)

今回はプーリング層でよく利用される、Max プーリングについて説明します。

なお、「プーリング」とは、画像処理で言う「ダウンサンプリング」にあたります。

Max プーリングはプーリングウィンドウ (ここでは出力) のうち、最も値の大きいものを選択します。

これは、フィルタに一致する [ニューロン](https://hogetech.info/ml/dl/neural-network#perceptron "ニューロン") が最も発火しやすい (高い値となる) からです。  
(言い換えると、フィルタに一致する要素があるか無いかを見たいので、一番高い値以外は要らない)

![](https://hogetech.info/wp-content/uploads/2022/03/40e3078c472ee171d679268e4eda7e8b-1.png)

![](https://hogetech.info/wp-content/uploads/2022/03/820aabd45e8d2549f8f78c60f073ca77-3.png)

７の位置が右にズレている

Max プーリングにより、フィルタの位置ズレを吸収し、「７」を検出できていることがわかります。

### LeNet in 1998

![](https://hogetech.info/wp-content/uploads/2022/03/lenet.png)

Full connection = 全結合層

Subsampling がプーリングに相当します。

LeNet は以下の７層から構成されます。

- 畳み込み演算層 ([Convolutions](#convolution) + [sigmoid](https://hogetech.info/machine-learning/deep-learning/dl-basic2#sigmoid "シグモイド") 関数) を１層
- サブサンプリング層 Subsampling ([プーリング](#pooling) に相当) を１層
- 畳み込み演算層 ([Convolutions](#convolution) + [sigmoid](https://hogetech.info/machine-learning/deep-learning/dl-basic2#sigmoid "シグモイド") 関数) を１層
- サブサンプリング層 Subsampling ([プーリング](#pooling) に相当) を１層
- [中間層](https://hogetech.info/machine-learning/deep-learning/dl-basic2#hidden_layer "中間層") ([全結合層](https://hogetech.info/machine-learning/deep-learning/dl-basic2#sum "全結合層") + [sigmoid](https://hogetech.info/machine-learning/deep-learning/dl-basic2#sigmoid "シグモイド")) を２層
- [出力層](https://hogetech.info/machine-learning/deep-learning/dl-basic2#output_layer "出力層") ([全結合層](https://hogetech.info/machine-learning/deep-learning/dl-basic2#sum "全結合層") + [Softmax](https://hogetech.info/machine-learning/deep-learning/dl-basic2#softmax "softmax")) を１層

### AlexNet in 2012

![](https://hogetech.info/wp-content/uploads/2022/03/alexnet-1.png)

入力は 224 \* 224 ピクセルの画像 (227 \* 227 の間違いでは？説もある) MATLAB では入力を 227 \* 227 としている

上下２つに分かれている理由は、当時の GPU では１枚に全ての [データ](#) が載らなかったからです。

AlexNet は以下の８層から構成されます。

- 畳み込み演算層 ([Convolutions](#convolution) + [ReLU](https://hogetech.info/machine-learning/deep-learning/dl-basic2#relu "ReLU") + [Max Pooling](#pooling)) で５層
- [中間層](https://hogetech.info/machine-learning/deep-learning/dl-basic2#hidden_layer "中間層") ([全結合層](https://hogetech.info/machine-learning/deep-learning/dl-basic2#sum "全結合層") + [ReLU](https://hogetech.info/machine-learning/deep-learning/dl-basic2#relu "ReLU") + [Dropout](https://hogetech.info/machine-learning/deep-learning/dl-basic4#dropout "Dropout")) を２層
- [出力層](https://hogetech.info/machine-learning/deep-learning/dl-basic2#output_layer "出力層") ([全結合層](https://hogetech.info/machine-learning/deep-learning/dl-basic2#sum "全結合層") + [Softmax](https://hogetech.info/machine-learning/deep-learning/dl-basic2#softmax "softmax")) を１層

### VGG in 2014

![](https://hogetech.info/wp-content/uploads/2022/03/831d293663dd9d697cf2dfcebd75134d-2048x567.png)

conv = Convolutions, 3×3 = フィルターサイズ 詳細：https://qiita.com/mhiro216/items/e54c2ff204512d877f98

Convolutions (畳み込み演算) を連続で行うことでフィルターサイズを小さくする手法です。

VGG は以下の計 16 層から構成されます。(VGG-16 の場合)

- 畳み込み演算層 ( ([Convolutions](#convolution) + [ReLU](https://hogetech.info/machine-learning/deep-learning/dl-basic2#relu "ReLU")) \* 2 + [Max Pooling](#pooling)) を２回で４層
- 畳み込み演算層 ( ([Convolutions](#convolution) + [ReLU](https://hogetech.info/machine-learning/deep-learning/dl-basic2#relu "ReLU")) \* 3 + [Max Pooling](#pooling)) を３回で９層
- [中間層](https://hogetech.info/machine-learning/deep-learning/dl-basic2#hidden_layer "中間層") ([全結合層](https://hogetech.info/machine-learning/deep-learning/dl-basic2#sum "全結合層") + [ReLU](https://hogetech.info/machine-learning/deep-learning/dl-basic2#relu "ReLU") + [Dropout](https://hogetech.info/machine-learning/deep-learning/dl-basic4#dropout "Dropout")) を２層
- [出力層](https://hogetech.info/machine-learning/deep-learning/dl-basic2#output_layer "出力層") ([全結合層](https://hogetech.info/machine-learning/deep-learning/dl-basic2#sum "全結合層") + [Softmax](https://hogetech.info/machine-learning/deep-learning/dl-basic2#softmax "softmax")) を１層

なお、各処理の詳細は以下のとおりです。

- [Convolutions](#convolution) の [パディング](#padding) は (1, 1) なので出力のサイズは同じ (64→64,...,512→512→512)
- [Convolutions](#convolution) [フィルター数の増加](#add_filter) により、チャンネルの次元を増加 (64→128...→512)
- [Max Pooling](#pooling) (= [ストライド](#stride) ２) により、出力のサイズを半分に (224→112...→7)

AlexNet のフィルター (11, 11) と比較して、VGG のフィルターは (3, 3) なので、 [少ないハイパーパラメータで学習可能](#reduce_param) です。

### GoogLeNet in 2014

![](https://hogetech.info/wp-content/uploads/2022/03/googlenet-1.png)

22 層で構成

GoogLeNet の最大の特徴は、サイズの異なるフィルター + Max Pooling の結果を結合する「インセプション構造」を持つことです。

![](https://hogetech.info/wp-content/uploads/2022/03/objectclassification_ref_googlenet_02.png)

https://arxiv.org/pdf/1409.4842.pdf

上記の図 (b) では、すべての要素に (1, 1) のフィルターを適用していますが、これはチャネル方向の次元を減らすためです。これにより、ハイパーパラメータの数を削減したり、処理を高速化可能です。

なお、インセプション構造を利用するモチベーションは以下のサイトにわかりやすく解説されています。

> 2013-2014 年当時、層を深くしたり、各層に存在しているユニットの数を増やしたりすることで、分類の性能が上がることが知られ始めた。しかし、少ない [データ](#) の中で、層数やユニット数を増やすことで、過学習を起こしてしまう。そこで、開発者らは Inception と呼ばれる [モジュール](https://hogetech.info/linux/kernel/what-is-the-kernel#software "ソフトウェア") を作り、その Inception [モジュール](https://hogetech.info/linux/kernel/what-is-the-kernel#software "ソフトウェア") を重ねていくことで、層を深くすることができた。
> 
> これまでのアーキテクチャは、畳み込み層を順列に繋げていた。このため、畳み込み層が深くなるにつれ、画像サイズが小さくなっていき、層を深くすることができなかった。これに対して、GoogLeNet では、1 つの入力画像に対して、複数の畳み込み層（1×1, 3×3, 5×5）を並列に適用し、それぞれの畳み込み計算の結果を最後に連結している。この一連の作業を [モジュール](https://hogetech.info/linux/kernel/what-is-the-kernel#software "ソフトウェア") としてまとめられ、Inception [モジュール](https://hogetech.info/linux/kernel/what-is-the-kernel#software "ソフトウェア") と呼ばれている。
> 
> https://axa.biopapyrus.jp/deep-learning/ [cnn](https://hogetech.info/machine-learning/deep-learning/dl-basic5 "CNN") /image-classification/googlenet.html

### ResNet in 2015

![](https://hogetech.info/wp-content/uploads/2022/03/resnet.png)

152 層で構成。|￣↓ 部分がスキップ構造 詳細：https://qiita.com/kenmaro/items/008051dae0bf0ad718cb

ResNet では、Convolutions 処理をスキップ可能な「スキップ構造」を採用しています。

![](https://hogetech.info/wp-content/uploads/2022/03/https-_qiita-image-store.s3.amazonaws.com_0_38555_8bf7b8e6-df06-a7d8-369d-2584d31cdb8c.webp)

https://arxiv.org/pdf/1512.03385.pdf

これにより、認識精度が上がる場合に層を深くし、学習がうまく行かない場合に畳み込み演算層をスキップ可能になりました。

## ディープラーニング (深層学習)

> 深層学習として最も普及した手法は、（狭義には4層以上 <sup><a href="https://ja.wikipedia.org/wiki/%E3%83%87%E3%82%A3%E3%83%BC%E3%83%97%E3%83%A9%E3%83%BC%E3%83%8B%E3%83%B3%E3%82%B0#cite_note-asou-3">[2]</a> <a href="https://ja.wikipedia.org/wiki/%E3%83%87%E3%82%A3%E3%83%BC%E3%83%97%E3%83%A9%E3%83%BC%E3%83%8B%E3%83%B3%E3%82%B0#cite_note-4">[注釈 2]</a></sup> の）多層の人工 [ニューラルネットワーク](https://ja.wikipedia.org/wiki/%E3%83%8B%E3%83%A5%E3%83%BC%E3%83%A9%E3%83%AB%E3%83%8D%E3%83%83%E3%83%88%E3%83%AF%E3%83%BC%E3%82%AF) （ディープ [ニューラルネットワーク](https://hogetech.info/machine-learning/deep-learning/dl-basic2#neural_network "ニューラルネットワーク") 、 [英](https://ja.wikipedia.org/wiki/%E8%8B%B1%E8%AA%9E): deep neural network; DNN）による [機械学習](https://ja.wikipedia.org/wiki/%E6%A9%9F%E6%A2%B0%E5%AD%A6%E7%BF%92) 手法である <sup><a href="https://ja.wikipedia.org/wiki/%E3%83%87%E3%82%A3%E3%83%BC%E3%83%97%E3%83%A9%E3%83%BC%E3%83%8B%E3%83%B3%E3%82%B0#cite_note-5">[3]</a></sup> 。
> 
> https://ja.wikipedia.org/wiki/%E3%83%87%E3%82%A3%E3%83%BC%E3%83%97%E3%83%A9%E3%83%BC%E3%83%8B%E3%83%B3%E3%82%B0

これは、 **「層を深くすることで error 率が下がる (推論精度が良くなる)」** という **経験則** に基づいています。一方で、 **理論的にはまだまだわからないことが多い** と言われています。

### 層を深くする利点

層を深くする利点は以下の３つです。

- パラメータの数を削減
- 少ない学習 [データ](#) で学習可能
- 特徴を他のパターン認識に流用可能

#### パラメータ数を削減

層を深くした場合は以下のように、 **少ないパラメータ数で同様** 以上の表現力を得ることができます。

| フィルターサイズ | 層 | パラメータ数 |
| --- | --- | --- |
| (5, 5) | １層 | 5 \* 5 = 25 |
| (3, 3) | ２層 | 3 \* 3 \* 2 = 18 |

![](https://hogetech.info/wp-content/uploads/2022/03/5620f8b95d8dc21a55807a504975eb0a-2.png)

#### 少ない学習データで学習可能

以下はすべて「７」を表します。

![](https://hogetech.info/wp-content/uploads/2022/03/40c3481dc3acebb7cf34dbf2f6394417.png)

[http](https://hogetech.info/network/protocol/http "HTTP")://yann.lecun.com/exdb/mnist/ より

これらを１層で学習する場合は１０種類の画像を学習する必要があります。

一方で、層を深く場合は１層目で以下のように４種類のパーツを学習します。

２層目では、１層目のパーツを組み合わせることで「７」を認識します。

![](https://hogetech.info/wp-content/uploads/2022/03/35704bb83de8f5267c45aabef3030536-1.png)

このように、層を深くすると簡単な特徴を学習するだけで良いため、少ないデータでも学習可能となります。

#### 特徴を他のパターン認識に流用可能

層を深くすると、以下のように最小の特徴から学習します。

![](https://hogetech.info/wp-content/uploads/2022/03/35704bb83de8f5267c45aabef3030536-2.png)

そのため、以下のように抽出した特徴を他のパターン認識に流用可能です。

![](https://hogetech.info/wp-content/uploads/2022/03/ff4c568dca7310c532b051c5cdea2dd8-1.png)
